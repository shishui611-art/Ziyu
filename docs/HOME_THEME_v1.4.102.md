# 首页与主题适配 v1.4.102

依据用户提供的 SukiSU 截图，以及固定上游提交 `075ac81f1dfe58b3f59c665a1b07fda8b975015f` 的 HomeMaterial/HomeMiuix。

## 布局

三套首页统一为大标题 → 大卡片 → 当前字体/字体库双卡片 → 有关错误/任务提示 → 设备信息 → DPI 与维护操作。
首页边距 16 dp、双卡片间距 12 dp。主题大卡片约按宽高比 1.76 布局，最低 200 dp，内边距 22 dp，长文字/大字号可增长，不硬截内容。
上游原卡片最低 188 dp；字域为图片空间稍增最低高度，旧版随文字收缩的情形现在保留稳定画布。
当前字体从大卡片移至左侧，点击可看完整名称及真实状态；右侧进入字体库。
信息卡列出 App/模块版本、Root 管理器、挂载方式、机型和 Android，生效检查仍可展开原有扫描/回滚/任务控制。

## 主题

- 首页与预览共用 HomeHeroFace，预览依据首页可用宽度缩放内边距、文字与高度；图片覆盖、圆环、贴纸渲染顺序一致。
- 使用主题强调色和强调色文字作为英雄卡默认配色；统计与信息卡使用卡片色，沿用卡片透明度。
- 接入上游 `home.status_working`、`home.stats_superuser`、`home.stats_module` 三个文字键，后两项分别用于当前字体与字体库卡片标题，数值仍为字域真实数据。
- 旧 `home.sample`/`home.current_font` 自动兼容到新的标题键；旧简短样例/装饰字键在文件中保留，不继续展示已无用途的编辑项。
- “显示卡片标题”控制大卡片大标题/副标题；“显示卡片装饰”控制圆环，图片存在时不叠加默认圆环。真实状态角标、错误与重启提示不会被主题文字替代。
- 上游卡片图片导入不加字域默认 35% 遮罩；字域包仍保留自设遮罩值。贴纸按卡片宽度定位，在文字上层绘制，支持浅深两套资源。
- 不移植上游超级用户、模块管理或 LKM 伪状态；页面职责仍是字体管理。

## 数据与资源

字体数复用 ViewModel 既有索引，区分已知、已核对与读取中状态。空库成功读取后为 0，未读不伪装为 0；缓存显示“上次记录”。不含系统默认入口、空 ID、重复 ID 与待删除项目。
计数使用 derivedStateOf，仅在字体索引或待删除列表等输入变化时重算；不随动画或任务百分比重复统计，不新增 Root 命令、目录扫描或轮询。
当前字体沿用 effectiveLabel，保留待重启、上次记录、失败等状态；详情不承诺未核实的挂载效果。
删除首页原有重复入口与不再调用的连接行；保留底栏入口及必要的失败/重启操作。

## Material 底栏

原先 Material+玻璃直接代理 MiuixAppDock，导致不会走 Material 文字横向展开；普通 Material 分支还在选中瞬间跳变 Row weight，animateContentSize 无法平滑兄弟项的重新分配。
Material 悬浮底栏统一改为自己的 MaterialExpandingTabs：260 ms 同步宽度/内边距与文字横向过渡、220 ms 颜色过渡。背景单独复用 ZiyuGlassDockSurface，不改变 Miuix/COUI 的导航。
拖动按本次布局相对于底栏的真实 tab 边界命中，保留滑动切换；点击、辅助功能、返回历史继续沿用原 onSelect/navigate。
非悬浮 Material 保留系统 NavigationBar。没有加入新的后台任务。
底栏真机动画流畅度、快速连点/拖动、RTL、预测性返回与窄屏/大字号仍需设备验证。

临时 Root 可见性排查另见 [TEMP_ROOT_VISIBILITY_v1.4.102.md](TEMP_ROOT_VISIBILITY_v1.4.102.md)，本次未实现或承诺系统级特征隐藏。
