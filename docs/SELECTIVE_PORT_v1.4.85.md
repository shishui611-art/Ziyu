## 本轮实现

1. RedMagicDigit、ZDigit / ZDigitVF 精确命名保护，角色 revision 3；同样约束兼容引擎和集合目标补齐。普通 Digit 不归入厂商时钟。
2. 设置 → 字体槽位规则：每行一个完整逻辑路径，白名单、黑名单、排除目录。黑名单先于白名单，白名单不能解除硬保护；目录按 `/` 边界匹配，`/system/product` 逻辑别名规范化为 `/product`。预览返回拓扑绑定确认令牌，新旧候选数量可见。保存使用原子替换、上一版有效备份、进程锁和既有切换锁；不提交字体或更改当前挂载。配置损坏停止新的自定义字体应用，保留当前状态，允许显式修复规则及恢复系统默认。缓存键采用规范化后的有效规则摘要，不以 JSON 排序、重复项或空白变化判定字体处理结果变化。
3. 系统文件选择器 → 导入前预览：一次保留当前文件，SHA-256 命名，复用原有有界复制和原生 TextView 渲染，确认后进入既有持久化队列。TTF/OTF 可直接预览，TTC 可切字面；WOFF/WOFF2 以系统实际能力为准，ZIP 只展示有界文件清单，不预解压。保留 32 文件和 256 MB 单文件限制。取消清理临时文件；异常终止遗留的过期预览目录在后续启动清理。
4. 字体应用确认：仅从已核验生效的 effectiveFont 取得当前侧，来源不明、系统默认和同一字体不误显示对比；两侧使用统一文字、字号和预览字重，预览参数不写入系统或字体配置，确认仍调用原有 applyFont。组合临时产物没有可验证字体库预览来源时沿用原确认/应用入口，不用最近选择冒充当前字体。
5. 任务与日志 → 故障复现记录：用户主动开始，120 秒 logcat 轮转上限，并由系统 timeout 保留独立时限。停止写入本会话标记，boot ID / PID 启动身份一致才请求运行中会话停止；采集者只终止自己创建的 Popen 进程组，重复 PID 或其他启动记录不用于杀进程。结束后生成结论优先的 report.txt / report.json 与 ZIP，原始文件在失败时保留，默认不读原始 ANR/DropBox。导出到既有用户 reports 目录，不自动分享或上传。

日志保存在 `/data/adb/ziyu/diagnostic-captures/<session>`，不增加 `/data/adb` 根目录散落文件。采集快照和压缩整理在实时采集结束后执行，界面显示“正在打包”。12 MB 是每份归档内容上限；原始日志与压缩包在磁盘上会同时存在。状态查看只读取记录，界面离开后不进行 App 轮询；没有开机守护或常驻预热。

性能优化与字体海报按手册暂缓；挂载提供者及 VFS bind mount 架构保持。保留原有源变化检查、输出校验、挂载验证和回滚条件，并增加规则文件身份检查，没有宣称切换速度提高。
