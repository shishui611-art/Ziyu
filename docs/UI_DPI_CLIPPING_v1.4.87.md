## 实际改动

应用任务返回 success 后、任何后续挂起前作废旧状态读取，立即显示已提交的字体名称。此时仅设置“待验证”或“待重启”，不伪造 effectiveFont 或挂载成功；后续实际状态与回滚结果有优先权。返回首页读取精简运行状态。读取失败保留已知选择并显示错误。

通知入口并入管理卡片，开机保护和 Google 兼容使用 SettingCard。共享卡片内控件间隔为 10dp，存储说明缩短；设置、备份、通知、导入和对比的用户提示删去实现原理和设计说明，保留 Google 兼容的影响/恢复及重启要求。未将日志原始诊断数据当作普通提示删改。

DPI 卡片始终显示，不按可变/普通/组合字体隐藏；没有 Root 或模块时提示连接。新 density 协议只比较前台用户和已有 DPI，重新读取并保留当时系统字号与粗细。它不写 font_scale/font_weight_adjustment，回滚也不覆盖同时发生的字号更改。旧 apply 协议为旧 App 保留，当前 App 已不调用字号写入入口。范围、结果核验和失败回滚仍执行。

防裁切入口移至设置，打开该页才加载现有字体索引，按所选字体保存；字体详情中移除原入口与 ColorOS 字样。ColorOS 继续已有适配，其他 ROM 在隔离的兼容暂存树内新增 font_clipping_stage.py，复用 SlotCompat 和集合逐面构建器，使用本机已验证原厂快照及相同的统一等比/基线计算。按清单处理已保留的实际字体槽位，角色和用户排除规则先执行；所有生成结果和来源确认后才替换暂存别名，原激活、挂载和回滚步骤保留。静态组合的集合仍交给原逐面流程验证，不重复处理。未开启防裁切时不启动新增适配。缓存身份纳入新增辅助程序；配置失效链接报错，不静默视为关闭。没有宣称速度提高或全 ROM 显示通过。
