## 已有证据

- stdout / stderr 基本输出正常；轻量键值握手返回完整模块身份、v1.4.96、versionCode 14096。
- 原环境及清除模块/Python 环境后的完整状态都为退出码 0、stdout 0 字节、stderr 0 字节。报告耗时精度为秒，两次均记录 0 秒，不能据此宣称耗时为 0 毫秒。
- 限时 trace 最后为 `. .../common/device_font_payload_runtime.sh` 后紧接 `exit 0`，没有到达状态 JSON 输出。当前证据定位到加载链提前退出，而不是已经输出完整 JSON 后被 App 解析器丢弃。
