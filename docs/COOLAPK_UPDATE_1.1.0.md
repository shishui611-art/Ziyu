# 字域 1.1 正式版来了

吧友们，1.1 这版我自己测完了，正式包放出来了。这次主要把字体组合和报错这两块收拾了一遍，界面也修了些之前看着不舒服的地方。

这次更新：

- 修了组合字体生成下一个字重时找不到原字体的问题，自动多字重可以接着往下处理。
- 某个字的可变数据坏了，符合恢复条件的话会保留这个字的原始轮廓，其他字照常处理。现在会直接告诉你“哪个字、哪个字重出了问题”，不用对着一句失败干瞪眼。
- 日志加了完整诊断导出。出问题请发完整报告，再说一下用的字体、字重和操作步骤，别只截一个“失败”，这样真的不太好查。
- Material、Miuix、COUI 三种风格都保留，调整了页面配色、底栏和卡片阴影，也去掉了 Miuix 详情页侧边的缝和整页背景圆角。
- 系统原厂字体也能导入字体库，拿来搭配中文、英文、数字。
- App 的包名和代码命名改成 Ziyu，版本号是 1.1.0，内部编号从 11000 开始。

升级提醒：这次换了包名，新 App 要重新给 Root 权限，旧 App 的设置不会自己搬过来，建议先备份再导入。模块里的已有字体继续兼容。本地 Debug 包和正式包也是两个应用，认准本次 Release 的 APK。旧 1.0 可能不弹更新提示，本次直接去 Release 手动下载 APK 和 ZIP 升级。

大字库组合还是会比较慢，尤其中文选自动模式时，要处理 100–900 九个字重。日志在往下走就说明还在算，最后看任务有没有成功。速度优化留到 1.2，这次先把当前版本跑稳，不画秒完成的饼。
