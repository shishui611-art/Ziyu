# 自定义文字与首页卡片（v1.4.101）

## 用法

设置 → 外观与主题 → 个性化：

- 自定义文字：修改首页标题、预览、导航和设置名称，留空恢复默认；按组还原。
- 首页卡片：选择图片，调整不透明度、遮罩、模糊、缩放及位置，最多加 5 张贴纸，可调位置、大小与旋转。
- 浅深主题的卡片分别编辑，一次保存两套；普通主题使用同一张卡片。
- 主题库导入时可关闭“应用主题文字”；图片、文字、贴纸同时参与主题导出和完整备份。

## 上游与边界

依据 SukiSU-Ultra main 在本次读取时的提交 `075ac81f1dfe58b3f59c665a1b07fda8b975015f`。
继续使用 v1–v4 数据主题协议、SKTH 认证解密、受限 ZIP 与字域扩展。
新增参考 `CustomTextConfig.kt` 与 `HomeCardStickerTransform.kt`；来源摘要和许可证见 `licenses/SukiSU-Ultra-theme-port.json`、`THIRD_PARTY_NOTICES.md`。

- 支持 `customHomeTitle`、可对应到字域的 `customTexts`、`card_background[_light|_dark]`、每套 `card_sticker_*` 及变换。
- 贴纸位置与大小以卡片宽度为单位，范围与上游一致；背景可保存字域自己的缩放、遮罩和位置扩展。
- 上游隐藏状态文字映射为隐藏“当前字体”标题，隐藏装饰映射为隐藏预览样例；实际字体名、连接状态和错误仍保留。
- SukiSU 的授权、内核、模块统计等字域没有对应功能的文字不套用，导入时明确提示未应用数量。不是每个上游配置都可一一映射。
- 自定义范围是外观标题和名称，真实字体名、错误原因、重启提示和危险操作确认保持真实。
- 上游账号、评论、投稿、Root 管理功能仍未引入；不捆绑或重新授权作者图片。
- 滑块调整贴纸，不包含上游拖拽/双指手势编辑；背景只解码静态帧，模糊需要 Android 12 及以上。

## 文件与事务

选图先在 `cache/themes/card-editor-*` 解码为有尺寸上限的 PNG；保存时仅提升新增图片到应用私有 `files/backgrounds`。
主题导入同样先完整校验候选及加密认证，再提交偏好。图片与元数据一起提交，失败保留旧外观，取消编辑只丢弃候选文件。
共享互斥锁串行图片提交与引用清理；提交与新文件所有权转移在同一不可取消段完成，避免关闭编辑器后误删已提交图片。
清理引用覆盖全局背景、两套卡片背景、全部贴纸，保留近期未引用文件一小时作为并发导入宽限。
固定大小解码只在图片路径变更时发生，不随滑块更新重复解码；没有后台动画或高频轮询。未做同条件设备性能测量，不宣称应用加速或降低发热。
完整备份继续通过 appearance.ziyu-theme 归档新内容；旧备份回退流程保留。
