## 修正

- 日常库与详情不传入固定字重。对比以空的轴覆盖开始，各字体使用自己的默认设置；手动调整后才应用指定值，恢复默认会清空覆盖。
- 对比控件展开后才调用现有 `rememberWeightAxisInfo`，使用已校验的真实 wght 范围与默认值；失败不显示假 400。使用浮点轴值，不固定或离散化源可变数据，不改用户组合权重。普通对比和应用不新增轴元数据读取。
- 两个现行内部信息展示入口使用同一格式函数。fvar/wght 是默认变化位置，OS/2 weight 是静态分类；二者不能相互冒充。源元数据与导出不变。
- 导入前预览已按所选字面读取轴默认值，继续保留；未据文件名猜默认值。本次未修改 Shell/Python 字体生成、挂载、输出校验或回滚。
