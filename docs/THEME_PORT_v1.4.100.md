# 主题库与自定义外观

入口：设置 → 外观与主题。

## 使用

- **主题库**：浏览、搜索、按分类和顺序筛选主题；支持单列/双列、详情截图、下载后预览。点击“应用”才替换当前外观。
- **导入**：选择 `.ziyu-theme` 或 SukiSU `.sukisu` 主题包。先读取并校验全部内容和背景，再显示预览；无效包不会覆盖当前外观。
- **导出当前**：保存字域 `.ziyu-theme` 包，包含配色、背景、卡片透明度、导航外观、图片效果和已导入的浅深两套外观。不包含本机路径、主题来源访问码、Root、字体、DPI、账号或手势设置。
- **自定义外观 → 配色**：分别设置通用、浅色和深色的主题色、按钮文字、文字、背景、卡片、分隔线和错误颜色。支持 HSV、透明度与十六进制颜色；每项可恢复自动或跟随通用。
- **背景效果**：调整饱和度、对比度、亮度、锐化、模糊与遮罩。锐化需要 Android 13，模糊需要 Android 12；旧系统保留配置并跳过不支持的效果。着色器创建失败时跳过锐化，不阻断主题和字体功能。
- **高级**：编辑同一份配色/效果 JSON，最多 16 KB；保存前检查版本、颜色和数值。普通操作不需要编辑 JSON。

Miuix、Material 和 COUI 接入相同语义配色，并分别映射到原生控件、Material 桥、全局卡片与预览。Material 没有单独的停用文字颜色角色，组件仍按原生规则降低文字透明度；不是把所有原生组件替换成 Material。

## SukiSU 兼容范围

本轮固定参考 SukiSU-Ultra `main` 的提交 [`075ac81f1dfe58b3f59c665a1b07fda8b975015f`](https://github.com/SukiSU-Ultra/SukiSU-Ultra/commit/075ac81f1dfe58b3f59c665a1b07fda8b975015f)，以及此前主题包、列表与下载接口的累计改动。查询时该提交为上游最新提交，不把之后可能变化的 main 当作相同源码。

支持 SukiSU 包格式 v1–v4、SKTH/AES-GCM 包读取、v3 浅深外观和 v4 语义颜色/图片效果。共享颜色先合并，浅/深颜色随后覆盖。背景在导入时一次规范化为长边最多 2048 像素的静态 PNG；浅深切换仅选取已保存的值和文件，不重复导入或转换原图、不写入偏好循环；显示时按需解码已规范化的 PNG。

导入 SukiSU 包时保留字域当前界面风格；导入字域自己的包时恢复其已保存的 Miuix/Material/COUI 风格。SukiSU 专用主页贴纸、卡片图片、主页自定义文字、模块列表排序、图标、AI、账号和手势项不导入；相关装饰在确认前说明。字体、Root、挂载、DPI、开机保护和连续可变字重不属于主题导入范围。

字域导出的是带 `ziyu` 扩展的 ZIP 数据包，后缀 `.ziyu-theme`；保留对应 SukiSU 语义字段和作者/许可元数据，但没有声称 SukiSU 可以直接导入字域包。主题作者的图片/内容许可不因客户端下载而改变，不将商店作品打包为字域自有资源。

手动调整配色保留浅深绑定；修改浅深主题的背景/调色参数时，将当前有效外观展开后保存，避免设置被未显示的另一半覆盖。背景效果编辑会提示“保存后固定为当前外观”。完整备份包含完整主题包，旧备份仍走原恢复路径。

## 在线来源与数据

使用上游代码明确内置的 SukiSU 公共主题来源及公开共享访问门槛。它不是字域运营的服务器，也不意味着服务可用性或第三方客户端兼容已经获得设备验证。首次连接前说明服务提供方与 IP/浏览下载请求；不同意时仍可本地导入、导出和调整外观。仅用户打开主题库后联网，没有启动预取或常驻扫描。

来源可更换为兼容服务。仅接受 HTTPS；访问码不随主题导出，配置和连接选择放在 App 的 noBackupFilesDir。更换来源时不自动向新地址沿用原访问码。文件和跳转必须同源；不开启全局明文 HTTP、不信任任意证书、不跨域转发访问码。默认过滤来源标记的 R18/NSFW 内容，本轮没有账号、评论、关注、投稿或上传操作。

目录上限 8 MB/10,000 项，主题包上限 128 MB；仅支持的版本允许下载。大包使用四个工作协程、2 MB 段与完成段账本；逐段检查 HTTP 206 和 Content-Range，来源不支持 Range 时使用单流。断点数据绑定来源/路径/大小/摘要；全部下载后核对长度和 SHA-256。下载进度限频更新，显示实际传输速度与估算剩余时间。预览下载并发上限四个，单图上限 4 MB；同图并发有互斥。缓存按大小和时间回收，不宣称这些源码优化已在手机实测提速。

主题导入限制条目数、压缩包/展开字节、JSON 和图片大小，拒绝目录穿越与重复配置/背景；不执行包内脚本。加密包必须读到结尾并完成 GCM 校验才可应用。背景先在缓存规范化，应用时只复制已校验图片到 App 私有目录，一次 DataStore 事务写入外观；失败保留原配置并清理本次创建的文件。共享图片事务锁跨 Repository 实例有效；仅回收未引用且超过保留时间的自有图片，避免删除另一个仍在导入的图片。
