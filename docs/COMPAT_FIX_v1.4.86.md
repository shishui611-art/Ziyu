## 本轮源码修正

- 槽位配置先检查链接，再判断缺失。通用入口、兼容缓存身份与切换锁均识别失效链接；兼容恢复默认不解析限制规则，避免规则损坏阻断恢复。显式保存仍可修复无效配置，保留之前的有效备份。
- 导入预览把元数据得出的默认字重和有效范围纳入初始化状态键。元数据晚到也能更新；普通重组不会覆盖滑块选择。仍复用原导入队列和渲染器。
- 当前侧新增只读 `current_font_preview.{py,sh}`：绑定当前 boot、字体名、路由结果、负载清单摘要，只导出 PID 1 实际可见且已证明应用的一个中文字体槽位。流式复制同时校验预期 SHA-256、文件身份及记录未变化，随后原子提交 App 私有缓存。没有字体库源文件依赖、不执行挂载、卸载、扫描或系统设置写入。只在打开对比时执行一次，拖动滑块不再次导出。进程缓存、应用自带字体及整套回退链不属于单文件预览的保证范围。
- TTC 在物理安全模式下复用原厂 XML 的明确中文 index；无法唯一确认字面的多字面集合不冒充第 0 面。当前侧无法确认时显示原因，仍允许确认目标；目标预览成功前确认按钮不可用。每次对比的目标侧使用新缓存身份并核对导出摘要。
- 组合页直接应用在字体库索引尚未刷新时也进入统一确认入口。生成组合的两种应用按钮统一进入对比；确认才提交原 applyPreparedCombination 流程，取消保留生成结果和重启选择。重启行为未提前执行。
- 新运行文件进入模块清单并登记为本项目独立 GPL 实现，没有新增第三方依赖。
