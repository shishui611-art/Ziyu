# MTZ 字体包导入

操作：字体库 → 导入 → 选择原始 `.mtz` → 确认。无需改名或解压。MTZ 在导入前按压缩包展示，导入后可用字库预览查看字形。

## 兼容范围

- MTZ 中的 `fonts/` 目录及根目录 TTF/OTF/TTC；大小写后缀均可。
- `fonts` 或 `fonts.zip` 字体组件，最多打开一层子压缩包。
- 字体目录及组件中的明文 `.mrc`、无扩展名字体；以真实 SFNT/TTC 文件头决定输出格式，不尝试解密。
- `description.xml` 中的简体中文名称，回退到普通名称或文件名；名称解析失败不妨碍字体提取。
- 按现有 ZIP 导入器规则选择主文字字体，保留同族多字重和斜体；可变字体不静态化，TTC 不拆字面。其他独立字体族和单独 Emoji 不保证导入。

## 限制和执行路径

输入最多 256 MB；合计最多 128 个字体，字体与嵌套组件读取共用 512 MB 展开预算；包目录最多 4096 项、4 MB，最多一层 fonts 子包。拒绝越界路径、符号链接、加密字体与不完整数据。忽略壁纸、图标和主题脚本；不执行包内程序，不安装小米主题，也不改变原有字体挂载方式。

文件选择器、预览、目录监视和导入队列均接受 MTZ。后台保留 `.mtz` 扩展名以进入专用提取分支，提取的字体继续通过既有格式和元数据检查再进入字体库。嵌套组件临时文件放在字域已有导入缓存中；中止提取会清理本轮输出，用户原 MTZ 不改写。

### 文件变化检查

从 v1.5.8 起，提取前后对同一打开文件核对设备、文件编号、大小及修改时间，再重新打开原路径核对同一组信息，以检查文件是否被修改、替换或删除。各次均使用文件描述符查询，不再将路径查询与打开文件的信息直接比较，避免不同查询视图造成误报。不增加整包复制或完整哈希；压缩包条目的 CRC、读取大小、字体格式和失败清理继续执行。

“文件在读取期间发生变化”仍表示本轮结果已丢弃，需要重新导入；若持续出现，请保留原 MTZ 和诊断日志。该版本针对检查方式不一致进行修正，尚未取得本次报错原包或完成真机复测，不能据此认定所有同文案错误都来自同一原因。
