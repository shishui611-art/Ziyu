# 字域使用指南

## 1. 安装与更新

### 首次安装

1. 从 [最新正式 Release](https://github.com/shishui611-art/Ziyu/releases/latest) 下载 `Ziyu-vX.Y.Z.zip` 和 `.sha256`。
2. 在 Magisk、KernelSU、SukiSU Ultra 或 APatch 中刷入模块 ZIP，按提示重启手机。
3. 重启后在 Root 管理器点击字域模块的「操作」按钮安装内置 App（刷入时已自动安装可直接打开）。
4. 打开 App 并授予 Root 权限，在首页确认模块与 App 版本一致。

### 模块更新

- **在线更新**：打开「设置 → 模块更新」检查 GitHub 正式版，校验 SHA-256 后由当前 Root 管理器安装模块 ZIP；完成后重启，重启后由模块自动更新内置 App（也可点击模块「操作」立即覆盖安装）。
- **手动覆盖刷入**：在 Root 管理器直接刷入新版 ZIP 并重启。升级会保留用户字体、挂载偏好与主题设置。

> 正式版只需刷入模块 ZIP，App 已内置其中；单独安装 APK 不会更新字体引擎与挂载运行时。

## 2. 选择挂载方式

在首页打开「字体挂载方式」选择模式，保存后按弹窗重启生效：

| 模式 | 适用场景 | 行为说明 |
| --- | --- | --- |
| **元模块自动挂载（推荐）** | 大多数设备 | 优先使用已识别的元模块或管理器内置挂载（如 NoMount、Mountify、Magisk/APatch 原生挂载）；不可用时回退字域自挂载。 |
| **字域自挂载** | 未装元模块或需独立挂载 | 跳过元模块，优先 OverlayFS，不满足条件时使用文件/目录镜像 bind。 |
| **Magic Mount** | 需要纯 bind 挂载 | 跳过元模块，使用文件 bind；遇路径别名冲突时自动建立目录镜像 bind。 |
| **OverlayFS** | 明确指定 OverlayFS | 仅使用 OverlayFS，不支持时直接报错并保留日志。 |

更多启动流程、软重启与排查方法见 [挂载方式与故障排查](MOUNT_FLOW.md)。

## 3. 导入字体与字库预览

- **导入方式**：在「字体库」点击「导入」选择文件，或将字体放入用户目录 `/sdcard/ziyu/fonts/`（可在「设置 → 用户文件位置」自定义目录）。
- **支持格式**：TTF、OTF、TTC（保留完整集合不拆分）、可变字体（VF）、WOFF/WOFF2、字体模块 ZIP、小米 `.mtz` 字体包（直接选择，无需改后缀；仅提取明文字体，不执行包内脚本）。
- **单包限制**：MTZ / ZIP 最大 256 MB，最多提取 128 个字体、展开上限 512 MB。
- **字库预览与导出**：点击字体卡片的「字库预览」可按分类查看酷安 53620096 完整测试语料与常用中英数标点，支持调整预览字号与复制原文；卡片菜单支持「导出 TTF」和「导出归档」。

## 4. 应用字体、组合字体与日韩字体

### 单字体直接应用

1. 在「字体库」点击目标字体，调整字重或可变轴（仅展示字体声明的可见轴）。
2. 点击「应用」，等待离线准备完成后按提示重启。

### 中英数复合字体

1. 进入「组合」页，分别选择中文、英文、数字字体及字重/可变轴，必要时调整英数缩放与基线微调。
2. 点击「保存方案」或直接「生成并应用」，以中文字体为基底合并英数字形并按本机原厂 TTC/OTC 结构生成负载。
3. 准备完成后重启生效。可随时从已保存方案快速载入并重新编辑。

### 日韩静态字体

- 在「字体库」导入静态日文或韩文字体并点击「应用」，字域按原厂语言路由替换假名/谚文及对应语言汉字，其余文字和缺字保留原厂。
- 当前日韩按语言路径支持静态字体；如需完整中文全局替换，仍请选择中文字体。

### 锁屏时钟与主题字体

- **保留锁屏时钟字体**：在「设置 → 字体工具」中可开关，关闭后允许兼容的时钟槽位参与替换。
- **主题字体**：厂商系统主题存储在 `/data` 的字体替换时会自动在 `/data/adb/ziyu/theme-store/` 保存原始备份；恢复默认字体或卸载模块前会自动按记录还原，遇部分失败可在页面点击「还原主题字体」。

## 5. Emoji 独立管理

入口：**设置 → 字体工具 → Emoji 管理**。

1. 点击导入 TTF、OTF 或包含单份彩色 Emoji 字体的 ZIP。
2. 预览确认后点击「应用」并按提示重启。
3. 文字字体与 Emoji 分别保存选择，更换文字字体不会丢失已选 Emoji，可随时在此页单独恢复系统默认 Emoji。

## 6. 外观、主题商店与图标自定义

入口：**设置 → 外观与主题**。

- **界面风格与配色**：支持 Material、Miuix、COUI 三套原生风格，支持自动/浅色/深色/纯黑、壁纸取色或固定色、液态玻璃悬浮底栏（不支持着色器的旧系统自动回退实体底栏）与 Android 14+ 预测性返回。
- **主题商店与主题库**：
  - 首次进入同意连接后自动获取访问授权，支持多内置镜像自动选路与故障转移，也可在「来源」添加自定义 HTTPS 源并测试 `/health` 延迟。
  - 支持分类/标签筛选、全屏详情页与可缩放图库、作者主页、「我的下载」离线库、「试用」模式（重启后自动还原，也可一键保留或立即恢复）及导入时按项勾选。
  - R18 内容默认隐藏，可在「内容与隐私」中开关或撤回同意。
- **背景与动态壁纸**：支持导入静态图片（PNG/JPEG/WebP/GIF/BMP/HEIF/AVIF）及 v6 主题包或本地 MP4 / WebP 动态壁纸，可设置缩放适配、静音、倍速与帧率限制。
- **个性化文字与首页卡片**：在「个性化」修改首页标题、预览文字、卡片背景与贴纸；想全部清除时点击页底「一键恢复默认主题」。
- **桌面图标与底栏图标**：内置 4 套字域图标（默认 / 蓝标 / 曜黑 / 极简线稿，均支持 Android 13+ 动态取色），支持导入单图或 ZIP 图标包固定桌面快捷方式，以及为三套界面风格自定义底部导航栏原色图标。

## 7. 重启、软重启与临时 Root

- **普通重启**：提交字体或切换挂载模式后，在弹窗点击「立即重启」或稍后手动完整重启，重启后在首页「挂载详情」查看生效状态。
- **内核软重启（FinaSU）**：在支持内核启动代次与内置 NoMount 的 FinaSU 环境中，重启弹窗同时提供「内核软重启」与「普通重启」。软重启会清理字域旧规则、激活新负载并尝试重置后续进程 PID 分配区间。
- **临时 Root 模式**：在「设置 → 临时 Root」启用后，可按提示通过管理器软重启完成激活，仍保留两次确认与结果回读。

## 8. 显示、通知、目录与备份

- **屏幕 DPI**：首页支持调整屏幕 DPI（滑块修改草稿，点击「应用」生效）；系统字号和粗细在手机系统设置中调整。
- **通知与实时活动**：在「设置 → 通知与实时活动」开启通知权限、「字体处理进度」通道及系统实时活动权限，应用字体时可在状态栏/胶囊查看后台进度。
- **用户目录迁移**：在「设置 → 用户文件位置」更改共享存储目录，下次完整开机校验迁移成功后启用，原文件保持完整。
- **完整备份**：在「设置 → 备份与恢复」打包导出字体设置、组合方案、外观配色、背景图片与图标配置，换机或重装后可一键恢复（主题商店访问授权不包含在备份内）。

## 9. 恢复默认、开机保护与卸载

- **恢复默认字体**：在字体库或设置点击「恢复默认字体」，等待完成后完整重启，即可撤回字域挂载并恢复 ROM 原厂字体（字体库与 App 设置保留）。
- **开机与 OTA 保护**：在「设置 → 管理与维护 → 开机保护」查看状态。
  - 连续两次开机未完成时会自动暂停自定义字体，建议先恢复默认字体并重启，再解除保护。
  - 系统 OTA 更新后如提示需核验原厂字库，按页面提示点击原厂扫描并重新应用字体，完整重启后自动解除保护。
- **卸载模块**：
  1. 如开启了 [Google 字体兼容](GOOGLE_FONT_COMPATIBILITY_ZH.md)，先点击「恢复原设置」并重启。
  2. 在 App 点击「恢复默认字体」并重启。
  3. 在 Root 管理器卸载「字域字体管理器」并重启（`/sdcard/ziyu/fonts/` 下的用户字体不会被删除）。
