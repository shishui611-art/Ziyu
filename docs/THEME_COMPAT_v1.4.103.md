# 主题文字与首页挂载入口 v1.4.103

## 故障路径与修正

原主题导入使用 JSONObject.optString/customHomeTitle 再调用 getString，空对象值可能被 Android JSON 字符串转换成字面量 null。ThemeTexts 只排除 JSON null 与空白，未排除已经字符串化并保存的 null，因而会进入首页标题、导航和预览。

现在只接受非空字符串；缺失、JSON null、空白、大小写不敏感的字面量 null 都视为未设置。首页标题恢复“字域”，其他文字恢复各自默认值。旧版文字键仅在新键无有效文字时作为回退。合法文字仍保留长度与控制字符校验；没有取消输入上限。

同一规则用于导入、保存配置读取、实时界面与预览；主题目录和包内名称、作者、说明、许可也排除空值。已保存的字符串 null 在读取时过滤，不需要清空 App 数据。该修改处理的是主题显示文字，并未引入主题字体文件安装或改变系统字体。

主页挂载入口原为无填充的描边按钮。现在复用 ZiyuCard，三套界面统一使用主题卡片底色、文字色与透明度，禁用时仍保留卡片底色；标题与选项分行，内容自然增高。沿用原点击回调与运行任务/Root/模块状态的禁用条件，不执行或改写挂载命令。用户主动设为 100% 透明时仍尊重该选项。

## 验证边界

本次按项目规范只进行编译、必要 lint、格式和包完整性检查，不新增或运行测试套件。另只读下载并认证解包实际“大肥鱼”主题，不能将静态解包或配置核对宣称为 Android 导入/真机复现；实包导入、旧偏好回退、三套 UI、浅深色及窄屏/大字号待设备验证。手机在本轮检查时已断开，未安装或刷入。

不改 Shell、字体生成或挂载运行文件，不新增第三方依赖。沿用已登记的 SukiSU 主题格式来源和许可证。交付版本由 module.prop 统一提供。

## 大肥鱼与配色修正

实际主题：`11045-01`，“大肥鱼”，作者“南何ovo”，853565 字节，SHA-256 `e8d9837037a208cdd98f2cc503d07fd9f9f6a101edc7259fbc1f72048b334efb`。SKTH 解包经过完整 GCM 认证；图片不随字域交付或进入源码。

其 v3 配置为 `uiMode=miuix`、`miuixMonet=false`、`keyColor=-11377248`、卡片不透明度 50%，浅深两套背景均使用 `customBackgroundScrimPercent=-35`，且 `themeMode=0` 跟随系统。固定上游中负遮罩表示黑色遮罩，正值为白色。旧导入截掉负值、忽略 uiMode，并把原生配色开关错误映射为跟随壁纸，会改变配色。原首页又统一取 Material onPrimary，无法匹配 Miuix 的主要文字色。

现在单独保存原生/Monet 配色与壁纸取色；显式 keyColor 优先，0 才跟随壁纸。读取 uiMode、每个浅深变体的模式，保留 signed 遮罩。旧字域的 0..100 页面色遮罩增加兼容标记，维持原含义；编码、备份、导出和读取同步保存新字段。旧变体没有新标记时继续继承外层模式/风格。

实时首页与预览使用共享 HomeHeroColors、appearanceCardBackground 和 backgroundScrimColor；首页标题及工具图标明确使用主文字色，不额外降低文字透明度。Miuix/COUI 每次从原生生成色复制快照后叠加主题，避免浅深切换复用可变颜色对象的旧结果。

宣传截图的浅色外观与手机深色外观不能视作同一条件；应用确认增加“跟随系统 / 浅色 / 深色”，预览与实际应用同一选择，保持明确的主题颜色。未做按图片猜色、强制所有主题使用黑字或改动系统字体。已有主题需重新应用，之前被截掉的配置无法从旧偏好凭空还原。

## 商店布局

商店改为全屏窗口：固定返回/刷新/布局/更多操作栏，滚动的大标题、搜索、标签、排序和图卡，底部导入浮动按钮预留安全距离。卡片展示主题源提供的热度/下载量、作者和日期，缺少热度不伪造。多选标签按任一匹配，自适应标记兼容显式字段和旧标签。

默认单列；宽度与字号允许时启用双列，宽图占满两列。徽标可换行，图片有渐变以保证卡片说明可读。主题应用仍需预览确认；关闭/取消沿用任务取消与缓存分段保存，不新增账户、投稿或上传服务。窗口内弹窗使用独立平台对话框，避免原生 PopupHost 被全屏窗口遮挡。
