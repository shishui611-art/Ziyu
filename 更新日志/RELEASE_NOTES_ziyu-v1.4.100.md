# 字域 v1.4.100（本地 Debug）

本次在 v1.4.99 基础上新增主题功能，尚未发布正式版。

- 新增主题库：搜索、分类、排序、单列/双列、详情截图和下载预览。
- 支持导入 SukiSU v1–v4 主题包，导出字域自己的主题包。
- 可以单独调整文字、卡片和背景配色，并为浅色、深色设置不同颜色。
- 背景新增亮度、饱和度、对比度、锐化、模糊和遮罩设置。
- 支持导入浅深两套外观，完整备份同步保存新主题配置。
- 下载核对文件摘要，导入先校验再应用；失败时保留当前外观。

入口：设置 → 外观与主题。首次浏览在线主题前会说明服务来源；本次没有账号、评论和投稿功能。SukiSU 专用的主页贴纸、卡片图片和专用文字不导入，主题确认页面会提示。

编译、打包与手机验收分别记录；手机显示、在线服务与主题互通仍待验证。未修改字体生成、连续可变字重、挂载、DPI 和开机保护流程，未安装、刷入或触发正式发布。
