# ziyu v1.4.11 — 本地显示配置与计划校验修正（本地 Debug 候选）

主页字体大小、粗细、DPI 原来重复调用 Android 服务读取，返回主页还会重复读取字体轴信息。本版将已确认的显示参数保存为本地配置，优先从本地读取；安装阶段在可用的系统服务中尝试初始化，失败由首次打开补齐。系统本身已持久保存显示设置，本版不增加开机重放设置的任务。

- 修改显示参数前仍读取并比较系统当前值，写入后回读验证，失败保留原有回滚；只有确认值写回本地。主页保留“同步系统参数”，供外部系统设置修改后主动刷新。ROM 指纹或 SDK 变化、无有效缓存或内部迁移标记为脏时重新读取。私有镜像和自选目录使用递增代次，避免临时不可写的旧副本覆盖新确认值。
- 设置的“文件与配置位置”新增显示参数配置目录。校验专用目录、原配置身份与复制内容后切换；保留原文件和内部小型镜像。外部存储暂不可用时读取内部镜像，不移动挂载与回滚状态。损坏缓存可重新初始化，缓存文件只按白名单解析，不作为脚本执行。
- 字体轴元数据按源文件设备、inode、大小、纳秒修改时间和变化时间缓存。命中时不加载字体解析库；实际源身份变化时重新解析。缓存写入失败不丢弃成功读取的能力结果，不缓存失败结果，旧来源文件数量有上限。
- 已完整匹配的原厂快照复用分支不再提前导入字体编译器；既有源身份、摘要与目标集合校验不变。其他启动扫描、Root/挂载状态与回滚检查没有改为无条件信任缓存。
- 用户当前手机 v1.4.10 日志在通用计划阶段报告 `文本目标包含无效动作：/system/fonts/NotoSansHanifiRohingya-Regular.otf`。计划生成尊重角色策略的保留动作，校验器却拒绝全部文本保留。本版允许角色策略明确保留的文本槽位，不扩大替换范围；未知字体自动替换和受保护角色规则保留。新计划修订号递增，旧修订 2/3 仍须通过完整校验。路由与编译器本来就不为保留动作生成替换产物。原日志后续兼容准备成功，不能把这条错误当作整个任务失败。

保留组合字体、字重能力判断、三主题组件、挂载选项、字体预加载、Google 字体兼容、用户文件迁移、完整备份与实时活动。减少重复工作是源码行为变化，具体启动或切换耗时仍需同一设备/字体条件实测。

交付需更新同一目录的 APK 和模块；仅安装 APK 不会更新模块脚本。本地 Debug 包沿用已有签名，不创建正式密钥。验证范围为源码语法、Android 编译和包完整性；读取了用户授权的现有手机日志，未安装、刷入或重启，未进行新版本手机功能验收，也不运行项目行为测试。
