# 字域 v1.4.85 本地 Debug 更新

相较正式版 v1.4.84，本轮增加：

- **更好地保护专用时钟字体。** 红魔、努比亚的 RedMagicDigit 和 ZDigit 系列不会被普通字体替换误处理。
- **可以自己缩小替换范围。** 设置页增加“字体槽位规则”，支持只允许某些文件、排除文件或目录。保存前先看数量变化，下一次手动应用字体时才使用新规则。
- **导入前先看效果。** 选择文件后可以预览、改文字、调整可变字重、切换 TTC 字面、移除不需要的文件。确认后才正式导入；不支持预览的文件仍可尝试导入。
- **切换前并排对比。** 当前字体来源已经核验时，切换到另一字体会显示相同文字和字号的对比，确认后才应用。
- **偶发问题更容易留记录。** 任务与日志页可开始故障记录，复现后停止并导出压缩包。最多采集 120 秒，自动限量；原始 ANR 和 DropBox 默认不采集，分享由用户自行决定。

这是本地 Debug 验证包。尚未完成手机操作、多 ROM 挂载与固定字库显示验收，不作为已通过完整验收的正式版发布。性能优化与字体海报按手册暂缓。
