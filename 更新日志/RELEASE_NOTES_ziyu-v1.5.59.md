# 字域 v1.5.59

## 修改

- 完整重启后按启动 ID 核对旧待重启标记；恢复系统默认字体后，当前启动的系统字体验证会清除过期提示。
- 临时 Root 应用字体完成后显示底部重启选择，提供普通重启、内核软重启和稍后操作。首页“选择重启方式”与刷新菜单使用一致选项。
- 内核软重启在 KernelSU 管理重载窗口执行有界 PID 分配回绕；系统启动后核对 zygote 服务已重建且新 PID 低于 5000。失败会写入软重启状态和日志，并在首页告知查看日志、使用普通重启。

## 验收说明

- 待重启标记与 PID 回绕/zygote 核验专项脚本通过；Shell 语法检查、Debug APK 编译及模块 ZIP 内置 APK 哈希/包名/版本/载荷清单检查通过。
- 手机尚未安装 App、刷入模块或执行软重启；当前设备上的字体挂载和 zygote PPID 结果待用户安装后实测。
