# 字域 v1.5.62

相较上一正式版 v1.5.7，本版修复静态字体集合的中文字体面选择，并汇总此后的字体切换、字体恢复和重启状态改进。

## 修复

- ColorOS 应用静态 TTC 字体集合时，根据中文覆盖、原字体字重与样式选择默认字体面。修复苹方默认读取缺少“远”（U+8FDC）的港版字体面，导致中文字符回退且粗细不一致的问题。
- 只调整 TTC 集合目录中的面偏移顺序，保留所有字体面和字体数据。按 XML 指定非零字体面的路径保持原有索引，可变字体继续支持连续字重处理。
- 修正字体挂载后的状态、框架软重启恢复流程和 PPID 结果提示，界面根据真实待应用、挂载和重启状态更新。
- 字体默认还原和卸载可恢复已备份的主题字体；主题字体管理保留单独备份和失败后的恢复记录。

## 改进

- 字体应用按本机发现结果选择必要槽位，核对原厂字体、字形和可变字重范围；来源字体缺字或证据不足时保留对应回退字体。
- 应用后提示重新启动的方式。临时 Root 页面和首页可查看 App 与模块的版本，并导出模块内置的配套 APK。
- 字体库状态复用已记录的模块和字体信息，减少刷新时重复扫描。

## 发布验证

- ColorOS OnePlus PLK110 上的苹方只读诊断确认第 0 面为 PingFang HK Regular，缺少 U+8FDC；第 2 面 PingFang SC Regular 包含该字。修复后的手机显示尚未验收。
- 本机 Release APK 使用既有正式证书签名；模块 ZIP 完整性、包名与版本、模块清单和 ZIP 内 APK SHA-256 核对通过。正式版以 GitHub Actions 正式签名及发布成品为准。
- 本次发布需由工作流执行源码检查与 Android 检查。完整手机字库覆盖与显示验收仍待完成，固定基准为 `coolapk-53620096-r1`，SHA-256 为 `e45b90d6244268251d69d9b95d0ae5f36df4b0174b8b6dce280236be2db30bd2`。
