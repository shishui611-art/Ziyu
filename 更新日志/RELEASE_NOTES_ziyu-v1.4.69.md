# 字域 v1.4.69（本地 Debug）

- 修复已抓到的两次 `IllegalArgumentException: Key Library was used multiple times` 闪退。根因是页面状态保存者随页面在懒加载分页器和返回预览间搬移，交接时旧的注册尚未释放，新位置再次注册同一个页面键。
- 每个页面使用固定场景位置和唯一状态保存者，取消跨分页器子组合的状态搬移。分页器仅提供测量、滚动位置和原有吸附行为，场景按该位置绘制页面；手势预览、完成和取消只修改图层。页面保持有界的相邻预备范围，避免永久保留全部页面。
- 保留实际返回顺序、滚动和筛选状态，以及固定背景层的玻璃采样；不改字体、挂载和 ROM 扫描。构建、包完整性及连接手机回归范围见本次交付说明，未验证场景保持待验收。没有上传或发布。
