# 字域 v1.4.7 本地 Debug：字体排除兼容候选

本版在上一工作副本 v1.4.6 上增加实际的撤挂载前字体预加载，针对开启 Zygisk Next「将非 Root 应用视为排除列表」及「仅还原挂载」时部分应用出现方框的反馈。尚未通过目标手机的开关对照验收，不能宣称方框已经消失。

- 随安装包部署独立的轻量「字域字体预加载」配套模块（ARM64、ARM32）。只有已有 Zygisk 能执行回调时才工作；主模块不增加根目录 `zygisk/`，防止无内置 Zygisk 时 Magisk 跳过主模块挂载。
- 仅消费当前启动已通过挂载校验的自定义负载，在应用特化前调用 Android 字体缓存接口，完成后卸载组件库；系统 UID 应用同样覆盖。默认字体、主模块停用/移除、旧启动记录、接口不可用或字体已不可见时跳过。
- 固定字域目录、限制文件数量/大小与 socket 收发时间，按代际复用清单，避免逐应用重扫和重复整文件哈希。保留现有源检查、字体输出校验、挂载校验和回滚；没有实测提速结论。
- 单项不可读、未挂载或超出上限时跳过该项并记录遗漏，不牵连其他已确认字体。只有启动/验证代际不匹配等核心条件才整体跳过。相同身份的配置不重复读取文本，清单合并传输，相同组件文件不重复复制，并移除不需要的动态库依赖。
- 配套组件可在管理器单独停用；升级保留它的停用/移除选择。主模块卸载只清理有字域所有权证明的组件。不会自动安装 Zygisk、修改排除策略、停用第三方 FontLoader 或增加 App。
- 诊断增加分 ABI 的首次预加载回调记录，区分调用数量与实际显示效果。包构建检查预加载源码、固定公共 API 头与两种二进制的一致性。

强制排除阻止 Zygisk 回调、回调前字体已被撤挂载、OEM 使用另一字体管线和非 ARM ABI 仍有限制，详见[完整说明](../docs/FONT_PRELOAD.md)。已有应用需重启，安装后需完整重启手机。

版本 v1.4.7 / 14007。本机沿用既有 Debug 证书，APK 可安装，但无法覆盖不同证书的 GitHub 正式版。生成新 APK 和内置完全相同 APK 的模块 ZIP，检查编译、签名、包名版本、原生 ABI/依赖/哈希、运行文件清单及 ZIP 完整性。没有新增或运行行为测试、手机安装、刷入、重启、上传或发布。
