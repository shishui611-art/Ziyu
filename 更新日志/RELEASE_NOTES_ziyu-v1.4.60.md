# 字域 1.4.60（本地 Debug）

这版完善了字体兼容处理和首页全局粗细的实际执行路径，并包含 1.4.59 的软重启后状态同步修正。

- 当字体没有系统需要的精确字重或斜体时，提前选择已有兼容引擎，并弹出一次“已切换兼容引擎”的警告。确认或关闭说明不会终止任务，进度继续显示当前处理阶段。
- 可变字体保留真实变化范围。例如字体支持 100–900，系统请求 1000 时采用边界粗细；900 和 1000 的显示可能相同，部分斜体效果也可能不同。不会把 900 标记成真正的 1000 字重。
- 通用引擎未通过、随后进入兼容处理的尝试按警告记录并保留诊断细节；最终失败、取消或子进程清理未确认仍如实报错。源变化、输出契约、挂载验证和事务回滚条件保留，挂载方式不变。
- 首页“全局字体与显示”中的粗细调整，增加系统运行配置同步与回读验证。原来只保存并读取设置库，新版还向系统传递粗细变化，并验证实际配置；失败时恢复原设置、核对回滚。没有重建整套字体，也不启用持续运行的粗细守护进程。
- 全局调整属于 Android 的字体粗细偏移，自带字体、固定字重或显式指定变化轴的应用界面仍可能不跟随。这不等于兼容引擎无法生成多字重字体。
- 包含回到前台同步字体运行状态，以及对同一请求已完成激活验证的任务清除过时“需要重启”提示的修正；未激活的队列和不一致负载继续保留等待或失败状态。
