# 字域 v1.4.87 本地 Debug

相较本地 v1.4.86：

- 应用字体后，首页立即显示新名称。需要重启或仍在验证时会继续提醒。
- 设置页更简洁。通知入口合并到管理卡片；开机保护和 Google 字体兼容使用统一卡片。输入框与按钮之间留出间距。
- App 只调整 DPI。字号和粗细请前往系统设置；普通、可变、组合字体和系统默认都能调整 DPI。
- 防裁切移到“设置 → 字体防裁切”。按字体开启，重新应用后生效；其他 ROM 也接入原厂字体边界适配，文字可能略小。

防裁切仍需可靠的原厂字体基准。可变来源请先在组合页保存静态字重；不支持的来源或校验失败时保留当前字体。应用内置字体、固定控件高度等情况仍需实际查看。

此为 Debug 包，尚未完成真机、多 ROM 防裁切和固定字库挂载验收。未运行测试套件；仅执行编译、运行文件导入/语法与包完整性核对。未自动安装、刷入或发布。
