# 字域 1.4.58

本次汇总 1.4.55 之后的字体显示修复、生成速度优化和模块更新改进。

## 修复

- 修复部分字体中 q、y、g、j 等下伸字母和 ff、ffi 等连写仍显示系统原字体的问题。超出原厂统计边界的正常字形会保留，并扩展相应边界，避免一段文字混用两种字体。
- 修复检查模块更新对额外校验附件下载的依赖：优先使用 GitHub 官方接口提供的 SHA-256，没有新版时不再下载校验附件；旧版发布没有摘要时仍兼容原有校验文件。
- 更新页会明确显示“当前模块版本高于线上正式版”。检查、下载及安装失败日志可随诊断报告导出，便于继续定位实际失败步骤。

## 优化

- 减少原生字形生成后重复解码、计算边界和重新编码的工作。
- 减少可变字体兼容处理中无关轮廓的复制与计算，复用 CFF 字形的边界结果，并让 HyperOS 的普通字体裁剪优先使用原生桥。
- 同一份字体和两个 ColorOS 字体面的桌面对照中，兼容生成阶段从 52.57 秒降至 25.16 秒，耗时减少约 52%。这是电脑上的特定兼容阶段数据，不能当作手机完整应用耗时。

## 使用与验证说明

- 保留原厂行距、竖排原点、字符映射、字体排版、来源变化、输出校验和失败回滚条件；特殊映射与原生接口暂不支持的转换继续使用兼容路径。
- 模块更新后需要完整重启。App 随模块 ZIP 内置，正式 Release 不单独提供 APK 附件。
- 本地 Debug 编译和包完整性检查通过；正式签名与发布包由本次 GitHub Actions 流程生成并核对。字体坐标、度量和布局契约完成桌面对照。手机显示、App 内真实模块升级及设备矩阵仍待验证；本次更新不代表所有下载或管理器安装故障均已验收。

如更新仍失败，请在日志页导出诊断报告，其中会包含模块更新的具体失败记录。
