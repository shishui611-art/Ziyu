# 字域 v1.4.19 — 正式版更新（相较上一正式版 v1.4.2）

GitHub 上一正式稳定版为 v1.4.2。v1.4.3 至 v1.4.18 是之后的本地工作副本记录，没有分别作为正式 Release 发布；本版汇总其面向用户的更新，并加入本次组合字体根因修复。

## 新增

- 增加主页系统字体大小、DPI 与设备支持时的字重调整；提供用户目录选择、经校验迁移、完整备份和主题背景图片。
- 增加字体任务通知、实时活动入口、通知状态引导和独立预览通知；主题页适配 Miuix 与 Material 并保留 COUI，新增配色预览、主题状态保存和 Android 14+ 页内预测性返回。
- 完善原厂 TTC/CID 集合逐面处理与记录。共享原厂槽位冲突、来源缺少字形或转换不安全时，可保留受影响原厂字形并继续安全的部分。
- 改进 Zygisk 字体预加载清单和回执诊断：只使用本次启动已验证的挂载清单，按序交错中文、拉丁字母和数字路径，并分别记录普通与 `PROCESS_ON_DENYLIST` 回执。

## 修复

- **组合来源覆盖判断**：`inspect_donor` 此前复用了 `globalUiCandidate` 的全覆盖门槛，使来源覆盖不完整时整面被拒绝。现在仍保留“中、大小写英文字母、数字”的基础探针，以及轮廓支持和非彩色检查；移除的是全量汉字、常用汉字比例和标点覆盖作为整面替换门槛。单字缺少来源字形时仍由既有逐字保留原厂机制处理，不因覆盖缺口放弃整面，也不扩大替换范围。
- **原厂集合验证参数**：一份历史 ADB 日志中五个 face 均生成 `PASS`，但后续验证命令传入的 `--source` 尚未定义，`argparse` 在验证实际来源前以 exit 2 退出，整项任务因此失败。本版让 CLI 接收一个实际组合来源 `--source` Path 并交给验证器；来源在过程中变化时仍按身份校验拒绝，并记录实际错误原因。修复参数错误不代表该次手机切换已通过。
- **状态查询入口**：`app_bridge` 的普通状态入口显式加载只读状态函数，并在调用可选函数前确认其已定义，避免某些加载路径下状态查询遇到未定义命令；不启用热切换，也不改变挂载策略。
- **真实字体来源容错**：多个字符映射到同一原厂槽位却提供不同轮廓时保留该原厂槽位，不再中止整个集合；个别字形超出原厂极端水平度量或轮廓无法转换时逐字保留并记录，其余可安全替换内容继续生成。
- **系统字体兼容**：ColorOS 静态字体路径保留原厂字符映射和安全的复合字形依赖；通用计划尊重显式保留动作。受保护 Google 字体的文件完整性处理也得到修正，系统验证限制不允许时仍保留原字体。
- **字体预加载**：清单生成按中文、拉丁字母、数字类别交错，防止大量别名先占满路径/逻辑映射额度；清单携带源和 PID 1 可见文件身份，兼容提供者复制或 Overlay 后两者 inode 不同的情况。原生端改为按挂载证明清单处理，不扫描目录、不读取 `/data/fonts`。清单传输与 JNI 完成回执使用独立连接，回执按 ABI 和代际保存。
- **交互修正**：组合结果、重启选择和回退对话框在 Miuix、COUI 与 Material 下统一使用对应主题组件；修正主题色设置行重复绘制底色；字体任务通知及实时活动点击后打开主页，任务中心仍可从主页进入。

## 优化与兼容性

- 原厂集合逐面编译按 CPU、可用内存与来源大小进行最多 3 个进程的有界并行，并在进程内复用已解析的来源轮廓和边界。源变化检查、逐面契约、输出哈希、证明、统一提交与回滚仍由父流程执行。
- 自动挂载沿用已确认提供者优先和条件化回退；字体生成复用单次来源计算、显示参数与字体轴元数据按设备/文件身份失效。新字体负载离线准备到下一启动，保留用户挂载选择、设备保护、输出与挂载验证。
- 桌面端对比不是手机端性能验收；Windows 环境无法使用手机侧 fork 并行路径，当前没有本版手机耗时或超时余量数据，不承诺实测提速比例。

## 验证状态与限制

十项集合回归检查、Android Debug 构建、双 ABI 原生构建与本地 51 项包完整性检查已通过，回归包含来源覆盖不足时保留原厂字形、验证命令接收一个实际来源 Path 并在来源变化时拒绝等场景。Windows 使用 ADB 只读导出的设备组合与原厂快照运行生产 build CLI，五面生成全部 PASS；随后 `validate --source --require-proof` 退出 0 / PASS。桌面单进程 build 耗时 278.250 秒，validate 耗时 12.719 秒；这是离线桌面数据，不与手机速度比较，也不代表设备切换通过。既有 `scripts/app_bridge_status_test.sh` 已 exit 0；状态、自挂载失败、过期证明、待重启、Universal 与回滚断言均通过。正式 CI 结果仍待定。本轮没有在手机安装、刷入、切换字体、重启或对照显示；设备矩阵继续待测。

预加载需要 Zygisk 实际执行组件回调，且已验证字体路径在回调时仍对目标进程可见。强制 DenyList 或其他策略阻止回调、回调前已经撤挂载、OEM 使用独立字体管线以及应用自带字体均不在保证范围。`invoked` 只表示 JNI 调用未抛异常，不证明具体字形已显示正确。
