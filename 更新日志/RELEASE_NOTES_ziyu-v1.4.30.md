# 字域 v1.4.30（本地 Debug 候选）

修复组合字体在部分可变 TrueType 原厂中文槽位中，字形轮廓取整后边界与侧距相差一个字体单位，导致兼容生成错误保留大量原厂字形、同一段中文粗细不一致的问题。仅调整一个单位的误差，较大差异仍由原有保护处理；保留原厂布局契约、源和输出校验、挂载验证及回滚。
