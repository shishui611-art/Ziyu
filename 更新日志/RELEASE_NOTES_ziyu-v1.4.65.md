# 字域 v1.4.65（本地 Debug）

- 修正 Android mksh 的状态分隔符模式解析，已有 OTA 待核验状态不会再被误判为无更新。
- 手动原厂扫描独立于 OTA 标记，实际扫描、生成拓扑并提交绑定当前 ROM 的回执后才返回完成；修正重新扫描时被旧回执提前判定完成的问题。
- 开机保护页提供手动原厂重扫入口，待扫描提示也覆盖非 OTA 情况，正常进入页面仍只读状态。
- NoMount 重定向下，扫描器在独立挂载命名空间中，以只读 loop 映射当前 PID 1 挂载的 EROFS 块来源，获得独立原厂 inode。校验来源、只读标记与设备身份，读取字体/XML 目录后释放专属映射；不卸载现有字体、不修改 NoMount 规则、不复制或扫描整块系统镜像。暂不扩展没有可信 lower/mirror 的非 EROFS 特殊来源。
- 同一供体生成且原厂不存在的 ColorOS CJK 兼容别名，复用真实槽位的已校验输出；保留实际不同供体和原厂独立槽位的处理。
- 早期桥派生入口继承已解析的模块绝对路径，避免 common/.. 路径使升级目录判断和连接路径缓存失效。

验证：本机 PLK110 / Android 17 / SukiSU Ultra + NoMount 已在隔离输出中完成原厂扫描：224 个字体路径、20 个槽位，单次约 5.97 秒。该数字仅代表这次手机扫描测量，不代表其他设备或总体切换耗时。构建、安装后手动入口与字体挂载验收以 dist 中本次报告为准；真实 ROM 更新、失败重试和其他设备尚待验证。保留源变化、输出、挂载、回滚检查。无 GitHub 上传或发布。
