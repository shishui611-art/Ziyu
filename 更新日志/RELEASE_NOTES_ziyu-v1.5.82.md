# 字域 v1.5.82

## 文字与 Emoji

已连接手机运行 v1.5.80。11 月 15 日 21:44、21:46、22:25 的文字切换均在保留 Emoji 时失败。当前 Emoji 记录仍指向 iOS Emoji，私有字体目录已为空，导入字库中相同 SHA-256 的原始 Emoji 文件仍在。原文字流程先核验旧 Emoji 挂载文件，导致文字自身已经生成后仍被拦住。

本次为 Emoji 增加独立选择记录。文字准备只决定文字选择，保留用户此前单独应用的 Emoji。优先从已导入资源重建旧副本，资源缺失时可保留经过核验的当前副本。两者均不可用时，文字仍可提交，Emoji 页面显示重新应用提示并保留原选择。

Emoji 准备使用独立暂存目录，完整准备后进入待重启负载。Emoji 单独应用与恢复默认，保留文字选择和当前文字验证记录。文字清理保留 Emoji 文件，旧文字缓存中的 Emoji 状态移除，已有缓存的文字内容继续使用。

独立选择随事务提交和失败回滚，兼容旧版事务快照。模块升级继承该记录，交付包携带运行文件及默认配置。

模块升级在新模块暂存目录内恢复有效 Emoji 副本，旧模块保持可读取。旧 Emoji 文件缺失时，可使用经摘要核验的导入资源恢复；不可恢复时保留选择和问题记录，文字负载继续按自身原始清单核验。默认文字搭配 Emoji 时重建对应字体清单与运行模式。

生成本地正式签名 Debug APK 和内置同一 APK 的模块 ZIP，核对包名、版本、签名、SHA-256、运行文件与 ZIP 完整性。
