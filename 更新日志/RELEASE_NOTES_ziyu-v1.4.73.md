# 字域 v1.4.73 本地 Debug 说明

相较本地 v1.4.72，本版统一当前代码和新产物里的项目命名：运行目录、命令、脚本接口、Python 启动器、字体生成名称、导出格式、旧 Android 源码目录及构建工作流改用 ziyu / Ziyu / ZIYU。

兼容处理：

- 旧字体库备份和组合方案仍可导入；新导出使用新标识。
- 升级时仍可识别旧版隐藏字体负载、已准备的重启事务和 Google 字体恢复记录。
- 已生成的旧字体、XML、证明文件和摘要清单保持原样，避免仅为改名而破坏完整性校验。后续明确应用字体时生成新名称负载。
- 原 GitHub 签名配置仍可用，新配置名称优先；App 包名与签名身份不因命名整理而改变。
- 旧路径迁移、卸载恢复、历史版权和第三方来源中的旧名有意保留，不能当作当前版本仍在创建旧目录。包内路径和残留分类见本次交付审计。

相较上一正式版 v1.4.70，本包还包含 v1.4.71 的 NoMount Suite 兼容、可信快照重新扫描、`/data/adb/ziyu` 数据迁移、旧组件退役和单模块显示，以及 v1.4.72 的日志导出与重启确认交互修改。目录升级请完整重启一次。

这是本地 Debug 交付。源码语法、Android 编译、实际 APK 版本/签名、模块清单和内置 APK 一致性检查以交付记录为准。未运行自动化测试，尚未进行本版手机安装、旧版升级、字体应用、备份恢复或重启验收；未上传 GitHub 或正式发布。无当前 ROM 完整可信快照时的底层 EROFS I/O 问题仍需设备日志定位。
