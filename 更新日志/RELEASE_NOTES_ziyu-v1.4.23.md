# ziyu v1.4.23（本地 Debug 候选）

## 针对 CFF/CFF2 集合的应用优化

ADB 只读日志确认设备目前安装 v1.4.21，最近一次应用成功，日历时间约 472 秒；ColorOS 适配阶段约 157 秒，原厂 CJK 集合生成阶段约 289 秒，集合最终校验约 17 秒。监督器记录的运行时间约 404.5 秒，与日历时间不同，不能混作 CPU 耗时。当前没有正在执行的字体任务。

该设备的 NotoSansCJK-Regular.ttc 包含 5 个 CFF2 字体面，每面替换约 1.7 万至 3.1 万个汉字。此前 v1.4.22 的不可变字形模板主要针对 TrueType，不能复用这些 CFF2 面的曲线转换结果。

本版在同一 worker、同一来源、缩放比例和 CFF 类型内复用转换并编码完成的 Type 2 字节，避免重复进行二次转三次曲线及指令优化。CFF1 的宽度编码纳入缓存键；每个目标面重新绑定自己的 Private、GlobalSubrs 和 FD 选择，不共享可变 CharString。缓存仅针对由轮廓生成的无子程序、无 hint/blend 指令内容，不复用原厂字形指令。CFF 与 TrueType 共用每 worker 最多 64 MiB 的额外模板预算，用尽后继续正常转换。

来源身份/哈希、原厂布局、逐字度量、输出回读、集合合并校验、挂载验证和回滚保留；未提高并行数或延长超时。新增逐面编译、保存、回读及集合合并耗时和 CFF 缓存命中记录，用于后续定位瓶颈。原有 TTF 导出等功能保留。

## 验证范围

本版执行 Python 源码语法编译、Android Debug/原生构建及 APK/ZIP 完整性核对。ADB 操作仅读取现有日志与状态，没有安装、刷入、应用字体、重启或运行性能测试。没有同条件新旧版本耗时对照，不能承诺加速比例；手机显示兼容和实际提速仍待验证。不上传或发布。
