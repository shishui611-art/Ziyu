# 字域 v1.4.76 本地 Debug 说明

字体库可以自行设置预览文字了：点击“预览文字”，编辑后保存，卡片与详情中的综合预览一起使用，关闭 App 后仍保留；也可恢复默认。为控制字体列表的渲染负担，最多保存 200 个 Unicode 字符，不拆开补充平面字符。详情的中文、English 和数字示例仍可单独切换。

模块管理器的“操作／播放”按钮现在会直接进入字域 App。未安装时，先安装模块内置 App，确认安装完成再打开；已经安装则直接打开，不在这个按钮路径上反复覆盖安装。兼容当前 Android 用户注册，安装文件仍使用既有完整性校验。系统未完成启动、App 被限制或安装失败时如实提示，不把安装成功当成打开成功。

相较本地 v1.4.75，修复一个会让人误以为字体没有应用完整的提示：旧版内部缓存字体已经通过实际字体文件使用，仍被校验器多算成“一个用途待确认的槽位”。新版同时识别当前和旧版内部目录，不再将这样的源文件计为未确认的界面字体。

这个修复不通过隐藏真实错误来判断成功：内部文件本身仍检查摘要；真实系统槽位继续检查文件内容、权限、路由和挂载；通过符号链接实际依赖的存储文件仍必须验证。确实只有部分位置生效时，主提示简要列出未通过挂载检查或待验证的数量，完整路径和原因在诊断报告中保留。

按用户提供的字库测试文本建立了 r1 固定语料。以后分别核对源字体、输出字库、系统回退、实际挂载和目标应用显示；私用区缺字不直接等同于挂载失败。测试资料见 `docs/FONT_TEST_BASELINE.md`。

包含 v1.4.71–75 的兼容、数据目录收纳与旧残留清理、单模块、日志导出、重启确认、ziyu 命名、刷入 Root 类型选择、搜索留白和体检路径修复。相较上一正式版 v1.4.70，为上述本地修改的累计 Debug 包。

本次字体路由回归、源码语法、Android 构建、实际 APK 包名/版本/签名、模块清单及内置 APK 一致性检查见交付记录。预览编辑/恢复/重启后保留、三种界面风格、模块首次安装/已有 App 打开和多用户行为尚待手机验收。设备上现有 v1.4.75 的只读字库和挂载观察不等于 v1.4.76 已安装验收；手机断开后未完成原生渲染与逐页视觉检查。未自动安装、刷入、重启、上传 GitHub 或正式发布。
