# 字域 v1.4.77 本地 Debug 说明

“设置 → 外观与主题”新增卡片透明度。可调节 0%–100%，查看效果预览，再保存或恢复默认。0% 为原有不透明外观，100% 让卡片底色完全透明；只调整卡片底色，文字、按钮、弹窗本身不整体变淡。设置由本地外观偏好保存，拖动滑块不逐帧写磁盘。

每次刷入模块默认普通 Root。之前升级刷入会沿用旧配置，旧值曾选择临时 Root 时，等待超时也会继续用临时 Root；新版不再把旧值作为默认。音量上键选择普通 Root，下键选择临时 Root，30 秒未选择或安装环境无法读取按键时均保存普通 Root。实际 late-load 会话仍自动识别，App 内也可继续修改流程偏好。

修复模块管理器点击“操作／播放”后，App 明明已安装却打不开、提示“请解锁手机后重试”的问题。

设备日志显示手机已经解锁，实际失败是系统无法解析只指定包名的启动 Intent。新版先查询当前 Android 用户的真实桌面入口，再使用完整组件名打开，避免依赖隐式 Intent 的默认类别匹配；不假设 App 包名与页面代码命名空间相同。使用常规桌面启动任务标志，已有任务可直接回到前台。

保留未安装时安装内置 App 后再打开、已有 App 直接打开的行为；已有 App 不因点击播放而重复安装或计算 APK 摘要。安装分支继续使用原有安装器与完整性校验。实际查询失败或启动失败会记录对应原因，不再一律提示用户解锁。

包含 v1.4.76 的自定义预览文字和内部源字体误报修复，以及 v1.4.71–75 的兼容、目录整理与界面修复。相较上一正式版 v1.4.70，为上述本地修改的累计 Debug 包。

设备诊断、当前 App 的显式入口启动、候选脚本核对、Android 编译及 APK／模块打包检查范围见本次交付说明。当前设备安装的旧包和临时目录中的脚本核对不等于 v1.4.77 App／模块已经安装验收。卡片透明度保存与重启保留、三种风格视觉效果、首次安装、多用户、Root 选项完整刷入和其他 ROM 尚待验收。未自动安装新版 APK、刷入模块、重启、上传 GitHub 或正式发布。
