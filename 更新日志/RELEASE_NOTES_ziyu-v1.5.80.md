# 字域 v1.5.80

## Emoji

- 入口位于设置中的字体工具，支持导入彩色 TTF、OTF 或含单份 Emoji 字体的 ZIP，提供字体样例、应用与恢复默认。
- 文字字体与 Emoji 独立保存，统一提交下一启动负载。支持默认文字配合自定义 Emoji，切换文字字体保留 Emoji 选择。
- 保留原始字体字节、彩色数据、字形替换与变体规则。Emoji 来源使用 SHA-256 索引，生成后再次校验输出，提交失败走现有事务回滚。
- 复用现有 Magisk、KernelSU、APatch 与元模块挂载选择，系统 Emoji 路由与文件内容纳入现有 PID 1 核验。界面区分本次启动、待完整重启和挂载待确认。
- 模块升级迁移已导入 Emoji、当前负载和待应用负载，诊断记录增加 Emoji 清单。
- 模块包预算调整为 14 MiB，Emoji 字体由用户单独导入。

## 验证范围

本轮按项目交付规范生成正式签名 Debug APK 与内置同一 APK 的模块 ZIP，并核对版本、包名、签名、内置 APK 摘要及运行文件清单。构建与制品核对结果随交付目录记录。

功能回归与手机验收待完成。待验证项目包括彩色渲染、ZWJ、肤色、旗帜、变体选择符、重复切换、待重启合并、模块升级、失败回滚、各挂载后端及不同 ROM。

本次实现系统 Emoji 替换。GMS/EmojiCompat 下载字体、应用自带字体和图片表情，以及动态字体更新优先级仍需专项适配。固定字库基准为酷安 53620096 r1，当前尚未进行手机覆盖验收。

旧版 XML 或 Universal 文字负载需先重新应用文字字体，再设置 Emoji，以建立当前负载与路由校验记录。

字体库整体滚动和普通重启回执修复随本次交付，设备效果待验证。轻量启动继续关闭自动 OTA/开机保护暂停与发布时全量校验。
