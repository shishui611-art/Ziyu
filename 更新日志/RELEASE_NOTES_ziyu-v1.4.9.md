# ziyu v1.4.9 — 实时活动与字体处理（本地 Debug 候选）

- 首次进入自动申请普通通知权限；拒绝后不在每次进入时反复申请。系统实时活动是独立开关，检测到关闭时只显示一次说明，用户点击后进入系统授权页，保留系统通知设置作为兼容入口。设置页可再次打开两类系统设置；不通过 Root 改写通知权限或厂商数据库。
- 点击应用、组合或删除时，在 Root 工作之前立即发布任务通知；前台服务请求立即展示，避免系统默认的通知延迟。Android 16 及支持的系统请求实时活动，携带简短胶囊文字和进度；旧系统继续普通进度通知。授权后及返回设置可重新发布进行中的任务。通知被拒绝不会终止字体任务。
- 正在运行进度服务时，返回桌面的任务进度读取间隔为 4 秒；不依赖页面保持打开。相同通知内容不重复发布，结束后移除进行中状态。系统仍决定是否展示胶囊、展示位置和用户撤销后的行为，不能保证所有 ROM 上岛。
- 字体库删除、应用及重新应用改用相同尺寸的主题实体按钮，删除使用错误容器色并带图标；Material、MIUIx、COUI 使用各自组件，保留使用中字体的删除限制与确认流程。
- ColorOS 度量按来源与契约去重后，独立槽位分组可在多个进程处理；通用编译按来源、字重和轴分组，保留准备实例缓存。使用已有 CPython 的 os/signal，不增加 multiprocessing 或第三方运行库，不绑定任何 CPU；根据进程允许的 CPU 与可用内存选择最多 3 个工作进程，预留前台内存，内存不足或不支持 fork 时串行。子进程适当降低优先级，避免与交互争抢。
- 并行阶段仅写本次离线暂存区，每个子进程单独使用 FontTools 对象和缓存；全部成功、源身份复查通过后由父进程统一提交。失败或取消回收本次子进程，保留输出校验、挂载验证和事务回滚。启动挂载与修改系统状态的步骤仍顺序执行。

验证范围：源码语法、Android 编译、原生组件及模块打包完整性检查；具体结果见交付目录。不自行运行项目测试，不安装、刷入或操作手机。尚未完成权限引导、桌面胶囊、实际字体切换、多进程取消和同条件耗时/内存真机验收，不能把并行源码改动称为已实测加速。

完整配套交付 APK 和内置同一 APK 的模块 ZIP，版本来自 module.prop，保留既有 Debug 签名。不可覆盖不同证书的正式 APK。

接口依据：[Android 实时活动](https://developer.android.com/develop/ui/views/notifications/live-update)、[系统实时活动授权页](https://developer.android.com/reference/android/provider/Settings#ACTION_APP_NOTIFICATION_PROMOTION_SETTINGS)。
