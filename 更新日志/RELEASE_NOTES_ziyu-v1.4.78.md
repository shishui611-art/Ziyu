# 字域 v1.4.78 本地 Debug 说明

针对卡片透明后，中间仍出现一块矩形色差的问题修正投影绘制。上一版本只改变卡片底色，仍保留原生硬件投影；圆角投影内部的遮挡区域在透明底色下会露出来，形成截图中的矩形边界。

新版在共享卡片和 Surface 上使用同一条投影规则：底色为半透明或全透明时关闭投影，以边框保留卡片边界；底色完全不透明时保留原来的投影高度。该规则覆盖 Material、Miuix 和 COUI 的可点击与不可点击表面，也覆盖原生卡片额外绘制的外部投影。没有对卡片内容整体设置 alpha，文字、按钮、布局、点击和按压交互继续保留。

保留 v1.4.77 的卡片透明度、自定义字体预览文字、模块按钮启动修复、刷入默认普通 Root 及之前的兼容修复。本次相较 v1.4.77 只修改 App 投影绘制及版本说明，没有修改字体生成、原厂扫描、挂载、校验或回滚脚本。相较上一正式版 v1.4.70 的累计字体流程差异仍包括 NoMount Suite 适配、可信原厂快照读取、数据目录迁移、旧格式兼容和实验性预加载组件退役，不能将本次局部不变理解为整个版本与 v1.4.70 相同。

Android 编译、APK 签名、模块 ZIP 完整性、打包清单与内置 APK 一致性以本次交付记录为准。未添加或运行测试。手机目前未连接，截图场景、0%／中间值／100% 透明度、浅深色和三种界面风格尚待新版真机验收；不能仅凭编译宣称已完成视觉验证。未自动安装 APK、刷入模块、重启、上传 GitHub 或正式发布。
