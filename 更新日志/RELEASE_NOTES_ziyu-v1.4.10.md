# ziyu v1.4.10 — 部分文字仍为系统字体修正（本地 Debug 候选）

依据用户提供的 v1.4.8 诊断与超级花伦丸字体归档：15 个负载槽位已挂载，但 SysSans-En、Roboto 等输出中部分英文字母与用户来源不同。通用路径另记录了未知槽位 `FZZWXBTOT_Uni.ttf` 的保留动作校验冲突。此诊断只代表采集时的负载和命名空间，不证明每个 App 实际选中的 Typeface。

- 通用计划与切换门禁共用未知槽位动作判断。显式保留原厂的未知槽位可以继续保留，不再让整个通用路径因此失败；未知槽位的自动替换仍被禁止。新计划使用递增的修订号，兼容此前已通过完整校验的修订 2 计划。
- ColorOS 静态来源套用原厂槽位契约时，保留组合字形引用的基础字母原来会从替换集连带移除。现在按需追加不进入字符映射的原厂部件副本，保留的组合字形引用副本，原有基础字母槽可以使用用户轮廓。仅复制受影响部件并复用同一副本；不复制整份字体，不绑定核心。
- 原有字符映射、布局、字形 ID、字重与可变轴声明保持；副本复制原轮廓、提示指令、水平/垂直度量、gvar 和 HVAR/VVAR 有效行映射。保存前后核对原厂契约及保留字形/副本内容。追加副本用稳定字形 ID 校验，兼容不保存字形名称的 post format 3。
- SFNT 字形容量不足时，只保留受影响的依赖链；真正越界、不支持的变化结构与源中没有的字形继续走既有保留处理。无可替换轮廓的槽保留可信原厂文件。保护不再通过无条件扩大保留范围来阻断其他可用文字。
- 字体诊断增加每个槽位的中文、英文、数字替换数和部件副本数；有来源身份、摘要和输出校验的缓存继续使用，修正相关脚本的字节变化会改变原缓存键。
- 保留组合字体、轴/字重与大小调节、挂载选择、预加载、Google 字体兼容、存储迁移、备份、三主题和通知功能。本版没有改变挂载后端或对实时挂载增加新操作。

更新同一交付目录的 APK 和模块 ZIP，然后重新应用字体，并按 App 提示重启。只安装 APK 不会更新模块内的字体引擎。

本地 Debug 包沿用已有签名，不创建正式密钥；不同签名的正式版不能直接覆盖。尚未完成手机字体效果、所有 ROM 的可变轴/提示指令行为和同条件耗时/内存验收；App 自带字体或原来未覆盖的系统路径仍可能保留原字体。不运行项目行为测试、不自动安装、刷入、重启或发布。实际编译和包完整性结果见交付目录。
