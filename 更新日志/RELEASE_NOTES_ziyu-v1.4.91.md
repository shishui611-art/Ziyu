# 字域 v1.4.91 本地 Debug

相较本地 v1.4.90：

- 减少开启防裁切后对同一可变字体的重复处理，继续保留连续字重调整。
- 同一字体共用经过校验的轮廓，再分别适配各处行高；部分位置的字可能比之前略小。
- 应用时显示正在测量、缩放、保存或校验，以及已完成的文件数量。
- 减少多个进程同时处理同一大字库的情况，保留取消和失败回滚。
- 修正“导入字体”按钮仍显示固定浅蓝背景的问题，背景、文字、图标与进度颜色跟随当前主题及深浅色。

此次优化主要针对 ColorOS 的可变字体防裁切。字体较大时首次应用仍需处理时间；CFF2 等原有不支持的格式限制不变。

此为 Debug 包。编译、语法与包完整性分别核验；未运行测试套件、安装、刷入或发布，新版实际速度、温度、显示与连续字重仍待手机验证。
