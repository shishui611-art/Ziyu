# 字域 v1.4.86 本地 Debug

相较上一个正式版 v1.4.84，新增专用时钟字体保护、字体应用范围设置、导入前预览、应用前对比，以及可手动导出的限时故障记录。

本次继续修正 v1.4.85 的三个问题：

- **当前字体对比更准确。** 左侧读取手机本次启动已通过验证的中文字体文件；原文件从字体库删除或换成了同名文件，也不会显示成错误的当前字体。右侧每次打开重新读取目标样例。无法确认当前字体时说明原因，允许继续原有应用流程。
- **组合字体也能先对比。** “应用并重启”和“应用，稍后重启”都先经过同一对比页；取消对比会回到生成结果，已保存的组合继续保留。
- **导入预览使用正确的默认字重。** 修正文件先加载、详细信息后到达时，滑块仍停在 400 的问题；拖动后的选择不会因普通页面刷新而重置。
- **字体应用范围设置不会悄悄失效。** 规则变成失效链接时，新的自定义字体应用仍会停止并要求修复；恢复系统默认字体继续可用。

用户提交的 v1.4.70 日志显示：NoMount 命令未识别，挂载停留在等待状态，同时原厂扫描的只读 EROFS 视图报错。当前代码保留 v1.4.84 已有的 NoMount Suite 适配和同 ROM 快照恢复，并针对这些路径补查。日志不能证明源字体损坏，也未显示 ROM 指纹发生变化；连接 GitHub 失败是另一个网络错误。

此包仅供本地验证，使用 Debug 签名。编译、包完整性检查、主机回归和真机验收分别记录；未安装或刷入反馈设备，不能据此声称该设备已恢复。系统更新、快照缺失或校验不通过时，不会把旧字体当作新的原厂基准。没有删除字体内容、挂载验证和失败回滚。
