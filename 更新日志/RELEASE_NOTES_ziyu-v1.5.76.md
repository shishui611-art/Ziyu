# 字域 v1.5.76（本地 Debug）

- 字体库使用多列预览卡片，常规手机宽度显示两列，宽屏增加列数，窄屏和大字号调整卡片宽度。卡片保留字体样例、名称与详情入口，进入详情后应用、导出或删除。
- 导入按钮直接打开文件选择。预览字体文件、预览文字、字体分析、系统字体添加与恢复、目录监听、备份导出和收藏标签整理移至设置的字体工具。
- 顶部支持批量选择与全选。确认删除后立即隐藏对应卡片，后台按批次串行删除，可继续添加删除任务。部分失败时保留已确认删除的结果，恢复失败项并显示原因。
- 保留当前字体恢复默认、待重启状态保护、删除回执、并发索引刷新保护和收藏标签恢复。队列在 App 进程内运行，切换页面后继续处理，进程结束后通过重新扫描核对已完成结果，尚未执行的队列需重新选择。
- 本轮未新增或运行本地回归，手机多列预览、文件导入、详情应用、窄屏大字号与后台删除待验收。字体生成和挂载继续包含 v1.5.75 修复，其设备验收状态保持待完成。
- 轻量启动继续关闭自动 OTA/开机保护暂停与发布时全量校验。APK 与模块 ZIP 的版本、签名、清单、哈希及完整性以本轮交付记录为准。
