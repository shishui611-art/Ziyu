# 字域 v1.5.9（本地 Debug，正式签名）

相比 v1.5.8：

- 修复模块更新后软重启误回退自挂载。KernelSU / SukiSU 的软重启不改变内核启动 ID，旧逻辑会恢复上次后端并跳过发布；模块更新已经替换模块目录，发布树与回执消失，外部挂载因此验证失败。现在会在 post-fs-data 恢复分支核对发布回执与发布树，失效时重新发布并交回元模块，post-mount 与 service 保持只读验证。
- 外部提供者验证通过后，清理字域自己的旧自挂载账本、lower/work 与 ext4 兼容镜像（本机旧镜像约 172 MiB）。仍有挂载、挂载表不可读或存在当前热挂载指针时保留账本，不卸载其他模块的目标。
- 修复备份与恢复的暂存目录校验：旧版 `ziyu-backup` 只认旧包名，当前 App 的暂存目录被判为“不受信任”；`full_backup.py` 又只接受 `/data/user/…`，拒绝部分 ROM 的 `/data/data/…`。两处现已统一支持四个历史包名、多用户和两种路径形态，同时保留非符号链接与 App 所有权校验；字体库归档导出的同源白名单同步修正。
- App 安装器区分签名冲突与损坏包：签名不一致时说明原因，不自动卸载；检测到旧包名残留时提示手动卸载，避免第二个桌面图标。
- 本版 Debug APK 使用现有正式签名构建，可覆盖已安装正式版；正式版与调试版不再形成两个 App。

更新模块后请完整重启。备份恢复修复需要 App 与模块同时更新，仅更新其中一侧不完整。

本次为现有正式证书签名的本地安装包。完成编译及包完整性检查；未运行功能测试，未安装到手机或刷入模块。软重启升级链路、旧镜像清理和备份恢复仍需真机复测，正式版发布与 GitHub 上传未执行。原有挂载模式选择、外部提供者优先、PID 1 路由校验、失败回滚、防裁切与可变字重流程不变。
