# 字域 v1.4.75 本地 Debug 说明

相较本地 v1.4.74：

- 搜索图标前方统一留出空隙，覆盖字体库、日志页、字体选择与字体检查弹窗，以及现有三种界面风格。图标采用共享槽位，正常图标距输入框起始边至少 16dp，清空搜索行为保持。
- 修复进入安全体检、点击安全清理时提示 `system/bin/ziyu-health: No such file or directory` 的脚本定位问题。App 会查找当前和旧版模块的隐藏目录、命令名称，不再仅依赖公开的 `system/bin` 路径；恢复默认字体也共用此解析。
- 新模块将体检实现放到 `common/ziyu_health.sh`，不随字体负载移动；保留原命令作为兼容入口。体检继续读取字体文件、挂载、切换任务、其他模块覆盖目标和近期日志；安全清理仅处理已确认失效的锁和任务记录，原验证条件保留。
- 安全页补充用途说明。若已安装模块完全没有任何体检脚本，仍需刷入本次模块补齐；App 不能凭空补出缺失的模块文件。

继续保留刷入时音量上键选择普通 Root、音量下键选择临时 Root，以及 v1.4.71–73 的兼容、单模块显示、目录迁移、旧残留清理、日志导出和命名整理。跨旧目录升级仍需完整重启一次。

相较上一正式版 v1.4.70，本包包含上述各轮本地修改。此次提供现有本地 Debug 签名的可安装 APK 与内置相同 APK 的模块 ZIP。源码语法、Android 编译、实际包名/版本/签名、模块清单、ZIP 完整性和内置 APK 一致性检查见交付记录。未添加或运行自动化测试，尚未进行手机安装、刷入、三种风格显示、新旧模块体检/清理或字体切换验收；未上传 GitHub 或正式发布。
