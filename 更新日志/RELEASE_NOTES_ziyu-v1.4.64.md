# 字域 v1.4.64 本地 Debug

修正连接模块时等待完整状态查询的执行路径，并接入 App 前台 ROM 检查与一次性自动原厂核验。包含本地 v1.4.59–v1.4.63 的状态同步、兼容生成、主页粗细提示、防裁切及手动扫描修正；本次不推送或发布 GitHub。

- 使用独立只读握手确认 Root、模块身份、版本与桥响应。冷启动定位模块不再额外启动一次 su；完整挂载状态仍后台读取，握手期间明确显示详细状态待读取，不宣称字体已生效。保留旧模块兼容回退。
- 每次进入前台比较系统 build 文件的 ROM 身份，未变化不启动完整字体扫描。首次没有可比基线只建立观察记录；读取失败不当作系统更新。确认记录变化或已有待核验保护时，后台扫描可信原厂字体和拓扑，不遍历整个分区，不自动刷模块、换字体或重启。
- 正在扫描则复用，同一 ROM 自动失败后停止自动重试，改由用户在开机保护手动重试。离开前台只停止 UI 跟进，不结束监督器中的扫描任务；扫描与字体切换互斥，运行总时限、源变化、输出、挂载及回滚校验保留。
- 清单和拓扑生成后才提交绑定扫描前 ROM 身份的核验回执。ROM 读取在扫描期间变化时不提交成功。已有成功的安装扫描结果可复用，默认字体恢复后的核验可完成收尾。
- 诊断导出包含 ROM 观察、自动尝试、核验回执及扫描/拓扑日志。Root 修改系统 build 文件仍可能表现为 ROM 身份变化；不能仅凭此记录证明真实 OTA，保留原厂源与输出验证。

## 验证范围

本地 Debug 编译、Shell 语法检查和包完整性检查；不添加或运行行为/性能测试。交付同版本 APK 与内置该 APK 的模块 ZIP，核对包名、版本、已有 Debug 签名、模块清单及 APK SHA-256 一致性。未自动安装、刷入或上传。连接耗时、同 ROM 不扫描、更新后扫描、自动失败不循环、手动重试及反馈设备的实际恢复均待手机验证，不承诺未经实测的加速结论。
