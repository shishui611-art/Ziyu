# 字域 v1.1.17

- 外部挂载提供者缺失、状态未知、排除本模块，或发布 / 最终字体路由验证失败时，自动切换到字域自挂载。
- Mountify / 其他 Root 提供者已经建立的挂载不会被盲目卸载；字域在当前可见字体目录上尝试 OverlayFS，不支持时使用已有目标文件的 bind。
- 挂载详情显示是否发生回退及回退原因；自挂载事务失败仍按实际回滚结果报告，不伪装为成功。
- 保留字域 `disable` / `remove`、外部 `skip_mount` 和未选择自定义字体时不注入的规则。

日常交付为 Debug APK 与包含同一 APK 的模块 ZIP；本版本尚未安装到设备验收。
