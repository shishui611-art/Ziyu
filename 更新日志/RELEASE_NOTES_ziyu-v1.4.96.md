# 字域 v1.4.96 本地 Debug

本次修正：

- 首次连接改用轻量握手，减少对 JSON 格式的依赖，继续兼容旧版模块。
- 修正 Root 回复可能漏读的问题，兼容前置提示和多行状态数据。
- 连接失败时保留已确认的字体，不再误显示为系统默认字体，也不继续预热字体。
- 故障复现记录统一放入卡片，按钮文字缩短，窄屏下可换行。
- 保留 FinaSU / Folk Mount 适配与真实默认字重预览。

这是针对“未收到 JSON 数据”的修复尝试，尚未在反馈问题的 NoMount Suite 手机上验证，不能认定该用户的全部原因都已排除。Root 未授权、模块被隐藏或组件损坏仍会如实报错。建议反馈用户使用匹配版本 App 与模块复测连接，若仍失败，导出故障记录。

FinaSU 普通 Root 的原生启动流程已接入，真机待验收。Folk Mount 不支持的独立字体分区不会冒充成功；FinaSU 临时 Root 软重启清理未适配，临时 Root 用户请勿直接完整重启验证。

本版为可安装 Debug 包，未正式发布。编译、语法和打包完整性分别记录；未运行测试套件，未自动安装、刷入、重启或上传。字体覆盖、连续字重、裁切与速度没有新增真机结论。
