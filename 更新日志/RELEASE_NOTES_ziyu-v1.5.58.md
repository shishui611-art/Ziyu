# 字域 v1.5.58

## 修改

- 修正安全扩展对 ColorOS 清单分组的依赖，按设备发现结果选取核心拉丁、CJK 和数字槽位；保留其它语种回退、主题装饰与特殊字体，锁屏时钟遵循用户设置。
- 补齐旁遮普、奥里亚、泰谭、加拿大原住民文字和变体假名字体分类，防止这些语言回退字体进入拉丁核心组。
- 按已选策略允许源字体缺少部分字符，由 Android 字体回退处理；保留可信原厂资料检查、复杂文字排版保护及连续可变轴范围校验。
- 将用户指定的对话表达规范补入 `AGENTS.md`。

- 已核对手机当前 v1.5.53 的只读记录：发现 100 个槽位，旧版本日志记载扩展 55 个；本次 v1.5.58 尚未在手机运行。
- 17 项原厂快照与扩展策略专项回归通过，修改过的 Shell 语法和 Python 编译检查通过。Debug APK 编译、模块 ZIP CRC、载荷清单、包名/版本/签名及 ZIP 内 APK SHA-256 一致性核对通过。
- 手机安装、刷入、重启和字体显示验收待完成；手机当前仍运行 v1.5.53。
