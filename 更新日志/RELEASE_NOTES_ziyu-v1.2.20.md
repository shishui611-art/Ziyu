# 字域 1.2.20

## 从 1.2.0 到 1.2.20

- **字体兼容与说明更清楚。** 部分字体缺少常用空格字形时会自动补齐；可变字体会复用已有空格映射，避免改动字形索引；通用处理路径遇到系统目标限制时，会列出具体目标和原因，再继续尝试兼容路径。
- **支持 KernelSU 临时 Root。** 如果完整重启会掉 Root，可在设置中启用 KernelSU 软重启流程；KernelSU late-load 环境会自动识别。软重启后请回到字域查看实际挂载和字体验证结果。
- **挂载方式有明确建议。** 当前适配方案中，使用 **KernelSU + NoMount 成功率最高**。设备和 Root 版本会影响结果，请以 App「挂载详情」中的本次验证为准。
- **组合字体更直观。** 组合卡片预览这次实际选择的字体，详情能看到中文、英文和数字分别来自哪款字体；已生成的组合字体不能再作为组合来源。
- **处理进度更容易查看。** 应用或生成字体时，通知栏会显示任务进度；日志页也会根据当前挂载和开机验证显示状态，修复重启后仍提示“等待重启”的问题。
- **切换操作更顺手。** 优化快速左右滑动切换界面的响应，并保留首页的酷安主页和 QQ 群入口。

## 遇到问题

请通过软件内首页底部的「酷安主页」或「QQ群」联系我。反馈时请附上机型、系统版本、Root 管理器，以及字域「挂载详情」或「字体刷写 → 日志」中的诊断信息，方便定位问题。
