# 字域 v1.0.0

这是 **字域（Ziyu）fork 的首个版本**，版本号从 1.0.0 独立起算。项目基于 [LuoShu 上游](https://github.com/xgl34222220-ops/LuoShu)，由酷安 [@柔性体](https://www.coolapk.com/u/28601616) 维护，优先适配 ColorOS 17。

## 本版内容

- 保留上游的原生 Android App、中文/英文/数字字体选择、复合字体生成和私有 systemless 挂载。
- 按设备实际字体配置扫描和映射字体路径，不依赖固定机型白名单。
- 包含 ColorOS 17 的字体路径与状态栏数字专项适配，同时保留其他 Android 系统兼容逻辑。
- 恢复全局系统字重控制，并保留字体文件自身的可变轴和多字重支持。
- App、模块和在线更新清单使用字域 fork 的版本及更新地址；不再提供 LuoShu 上游安装包作为本项目更新。
- 字域使用独立 App 签名；不能直接覆盖安装 LuoShu 上游签名的 App，相关数据迁移请先自行备份。

## 安装与验证

请只从本仓库的 [Releases](https://github.com/shishui611-art/Ziyu/releases) 下载模块 ZIP。刷入前关闭 Root 管理器中的“默认卸载模块”，刷入后完整重启，再安装或更新模块内置 App。

设备覆盖情况以 [真机验证矩阵](docs/TEST_MATRIX.md) 为准。自动化构建和源码测试不能替代目标设备的安装、开机、应用、字体恢复和卸载验证。

## 升级编号

字域显示版本从 v1.0.0 开始；Android 内部 `versionCode` 为 80000，保持高于上游 2.0.0 系列的 70000，支持覆盖安装。后续字域版本继续递增内部编号。
