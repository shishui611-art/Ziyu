# 字域 v1.5.66

修复苹方字体中“远”字粗细不一致，并保留用户设置的模块停用标记。

## 修复

- 迁移旧版 `skip_mount` 与 `skip_mountify` 时，只认领空标记。带内容的标记按用户设置处理，启动时继续阻止挂载，释放流程不会删除其内容。
- ColorOS 使用静态 TTC 集合时，按中文覆盖、来源字重与样式选择默认面，修复苹方第 0 面缺少“远”（U+8FDC）导致的粗细混杂。
- 保留 TTC 集合中的全部字体面与原始数据、显式非零面索引路径及可变字体连续字重处理。
- 修正 HyperOS 字体度量回归夹具的暂存状态复用，避免正式源码检查将生成别名误判为受保护的 ROM 字体。
