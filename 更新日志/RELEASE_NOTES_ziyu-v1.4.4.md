# 字域 v1.4.4 — 本地 Debug 自动挂载回退候选

## 挂载策略

刷入模块时显示已保存的挂载选择和启动回退计划。完整重启后，自动模式优先使用确认可用的元模块或 Magisk/APatch 内置挂载；未检测到可用提供者、发布或路由验证失败时，保留已有的字域自挂载回退。Root 管理器身份无法识别时，新版明确选择字域 Magic Mount / bind，跳过默认 OverlayFS 尝试。

未知身份仍记录为 unknown，不假装检测到 Magisk，不安装 Magisk，也不调用未确认的管理器控制接口。策略复用字域已存在的 bind 与字体别名目录镜像实现。

自动回退的模式和原因记录在本次启动状态中，service 继续验证并按原条件处理有限重试和回滚。auto 偏好不会永久改成 magic/self_mount，下一次完整启动重新检测。手动指定的 OverlayFS、Magic Mount、字域自挂载继续使用原选择；停用、删除、外部排除、启动保护和 OTA 保护继续生效。

## 执行位置与限制

安装器的模块目录可能仍是 modules_update，且其挂载命名空间不一定属于系统。刷入阶段只准备策略，真实字体挂载在管理器调用启动 hook 后执行，不把 ZIP 安装完成当作挂载成功。PID 1 内容与路由验证失败时仍回滚并报告失败。

未知管理器仍须具备可用 Root、模块启动入口和允许字域执行挂载的权限。该回退不能代替缺失的启动 hook，也不能保证应用隔离后仍可访问字体。尚未完成 APatch、Magisk、KSU 或未知管理器的本版手机验收。

## 字体与交付

包含 v1.4.3 的 ColorOS 静态字体原厂字符映射保留修复候选及其限制；本次没有新增 Zygisk 依赖或修改应用隔离设置。

版本统一为 v1.4.4 / 14004，构建 Debug APK 与内置同一 APK 的模块 ZIP。检查语法、Android 编译、签名、包名版本、SHA-256、清单与 ZIP 完整性；未新增或运行行为测试，不自动安装、刷入、上传或发布。不根据源码推断手机实际耗时或字体显示已通过。
