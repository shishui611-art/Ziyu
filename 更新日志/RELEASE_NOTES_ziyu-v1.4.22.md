# ziyu v1.4.22（本地 Debug 候选）

## 组合字体应用

跨原厂字体面复用同源、相同缩放比例的 TrueType 转换字形，模板保存为不可变 glyf 字节，每个目标面重新生成独立 Glyph 对象。共享模板不包含目标面垂直变化、字重或布局状态；这些内容继续按每面原厂契约处理。单 worker 模板预算为 64 MiB，包含估计字典开销；预算用尽时继续原有转换路径，不影响功能。并行 worker 估算加入该预算，仍受 CPU、可用内存、总时限约束。CJK 集合每个 worker 只打开一次来源字体。

来源身份、哈希、原厂布局、逐字度量、输出回读、集合合并后验证、挂载验证与事务回滚继续保留。v1.4.21 的单调运行时钟、临时 CPU 唤醒锁和 CJK 阶段有限预算继续保留。

## TTF 导出

字体库卡片新增“导出 TTF”按钮，导入字体、已保存组合字体使用同一入口。先选择字重或字体面，再通过 Android 文件选择器选保存位置。

- 单面 TrueType 字体按原字节导出，可变 TTF 保留可变轴。
- TTC 选择其中一个字体面提取为 TTF，保留该面的字符和布局。
- CFF/OTF 真实转换为 TrueType 二次轮廓，去除原 CFF 提示信息。可变 CFF 根据默认轴导出静态实例并明确提示；这不影响原字体库中的可变字体。
- 转换文件回读验证 TrueType 表、字符/字形索引数量、排版表、来源未变化和 SHA-256。导出来源为字域字体库快照，不修改原字体或系统挂载。
- 原 ZIP 归档保留，同时修正 Root 复制后私有缓存所有者与访问标签。
