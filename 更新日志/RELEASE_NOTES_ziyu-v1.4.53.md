# 字域 v1.4.53 本地试用说明

新增原生 CFF/CFF2 目标字形转换，包含 v1.4.52 的软重启清理与两层跟手返回修正。本次不上传或发布。

实现

- 在现有固定 HarfBuzz 原生工具中增加 --cff-cache 批处理入口。TrueType 供体复用现有受限轮廓解码器，原生完成轮廓分解、二次曲线精确升阶、方向反转、缩放、整数舍入、边界及 Type 2 编码。CFF/CFF2 静态供体通过 HarfBuzz draw API 读取轮廓。
- 缓存保存不依赖目标私有字典的曲线主体；发布时按每个原厂 FD 的 defaultWidthX/nominalWidthX 编码字宽，分别处理 CFF1 endchar 和 CFF2 无字宽/无 endchar，保留 FD 选择、字形 ID、cmap、GSUB/GPOS/GDEF、可变轴和现有布局契约。
- 多面集合在父进程按目标 UPEM 准备一次不可变缓存，有限 worker 只读复用，减少每个 worker 重做同一轮廓。64 MiB 缓存总预算与现有原生字形/轮廓模板共享；源变化、取消、最终输出验证、挂载验证和回滚条件保留。
- 非标准 CFF FontMatrix、不能保证整数舍入的浮点边界、点匹配复合字形等由原有路径处理。少量运行时合成连字也保留现有转换。字体组装、契约校验、CFF 转 TrueType 等路径尚未全部原生化。

本地验证

- 桌面静态 TrueType 供体、同一原厂 NotoSansCJK 字体面，原路径 46.722 秒，原生路径 5.989 秒（含生成和保存；先原生后原路径交叉顺序复核）。原生预处理约一秒。此数字不是手机完整应用耗时。
- 重新打开两个输出，65535 个字形几何轮廓、字宽及原厂契约一致。对共线线段做等价归一化，未发现几何差异。
- 单面文件从 25070672 字节增至 26064172 字节，约增加 3.96%。原生使用保守的 Type 2 编码压缩，目前未完整复制 FontTools 的指令优化器；以输出体积小幅增加换取转换提速，不改变曲线形状。
- 720 项轮廓/字宽对照通过；含原生实例化、原生 CFF、共享准备与源变化拒绝的 14 项检查通过；原厂集合 11 项回归通过。未运行完整 CI。

原生 ARM64 构建、APK 编译和模块完整性检查结果见交付目录。本机字体切换与新包挂载验收尚待试用；未自动安装 APK、刷入模块、重启或发布。

尝试核对 ARM64 手机临时转换时 ADB 已无设备连接，因此未在手机运行新工具；不将桌面输出对照记为手机验收。
