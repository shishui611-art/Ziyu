# 字域 1.5.0

相较上一个正式版 **1.4.84**，本次更新包括：

## 新增

- **主题商店与主题导入导出**：浏览、下载和应用主题，也能把当前外观导出分享。
- **首页个性化**：可以修改首页文字、卡片背景和贴纸；下方直接查看当前字体与字体库数量。
- **一键恢复默认主题**：不喜欢导入后的效果，可以在外观设置中还原背景、配色和自定义文字。
- **字体应用前对比与问题记录**：导入、应用前查看字体效果；遇到偶发问题时可手动采集并导出记录。

## 修复

- **主题商店“拒绝访问”**：适配新的自动授权方式，旧版用户无需手动复制访问码。
- **模块连接与状态读取**：修正部分 NoMount 环境下的脚本读取和状态返回问题，减少一直等待模块连接的情况。
- **部分字体挂载检查误报**：分别核对不同系统字体文件，避免内容正常却提示一处未通过检查。
- **原厂字体扫描提示**：扫描完成后可以直接前往字体库重新应用，不再反复显示需要扫描。
- **主题显示与状态栏**：修正空文字、文字与背景融在一起、部分透明效果不一致，以及背景未铺满顶部的问题。
- **返回与滑动操作**：按实际来路返回，调整预测性返回的页面衔接，减少上下滚动时误切换页面。

## 优化

- **防裁切支持更多字体和系统**：可变字体继续保留连续字重调整，复用可用的处理结果，避免不必要的重复处理；效果和耗时因字体、设备而异。
- **显示设置更清楚**：App 调整屏幕 DPI，字号和粗细直接前往系统设置；应用、刷新和恢复默认按钮更明确。
- **字体应用反馈更及时**：应用后更新当前字体信息，区分等待重启、部分兼容提醒与真正失败。
- **提示更简洁**：设置、预览和弹窗使用更直接的中文，详细原理留在仓库使用说明中。

更新请刷入完整模块 ZIP，仅安装 APK 不会更新模块中的字体处理与挂载组件。设备矩阵仍有待测项目，自动检查和打包不能替代手机验收；如遇异常，请导出日志并附上机型、系统和 Root 管理器版本。
