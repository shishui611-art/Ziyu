# 字域 1.4.61（本地 Debug）

本版在当前本地 1.4.60 的基础上，按用户要求停止由主页修改全局字体粗细。已拉取核对 GitHub：远端 main 为 1.4.58；保留本地 1.4.59、1.4.60 的其他修正，本次不上传或发布。

- 删除主页粗细滑块，换成前往手机系统设置调整字体粗细的提醒，Material、Miuix 和 COUI 共用同一修改。
- 字号与 DPI 调整固定保留系统当前粗细；“默认数值”不再把粗细归零。删除对应的全局粗细写入、回滚写入和 Root 运行配置桥；旧版客户端发来的粗细修改请求返回说明，不执行写入。
- 系统粗细值改变不再阻止无关的字号、DPI 调整。Android 用户、字号和 DPI 的提交前检查、输出回读与失败回滚继续保留；字号和 DPI 回滚不会改动系统粗细。
- 首页读取参数不再为粗细控件解析字体能力。字体工作室和组合字体中的选轴、多字重仍可正常使用。

## 验证范围

本次只进行 Android Debug 编译、Shell 语法和 APK/模块 ZIP 完整性核对，不添加或运行行为测试。独立 APK 与模块内 APK 核对包名、版本、签名与 SHA-256，模块按当前工作副本清单打包。手机中主页提示、字号/DPI 与系统粗细共同使用的效果仍待用户验收；没有自动安装、刷入、重启、上传或发布。

已有粗细值不会因升级被强制清零；如需改变，请在手机系统设置中手动调整。美团文字顶部裁切尚缺具体字体与当前诊断，本版没有修改轮廓、行高或基线，不宣称该问题已修复。
