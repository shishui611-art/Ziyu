# 字域 v1.4.72 本地 Debug 说明

相较本地 v1.4.71：

- 日志页可以直接看到“导出日志”，就在“清空日志”旁边。导出时显示进度，避免重复点击和误清空正在导出的日志。
- 报告统一保存在当前字域文件夹的 `reports` 子文件夹，完成后可复制保存位置。导出包含诊断信息，不受页面搜索和筛选影响。
- 软重启第一层确认改成明显的按钮，写明“继续选择重启方式”；最终执行前仍需确认。挂载方式修改后的重启提示使用相同按钮样式。
- 选择重启方式时先显示检查进度，连续点击不会重复检查，关闭后不会因检查完成再次弹出确认框。此项改变界面反馈，不代表已实测缩短模块响应时间。

相较上一正式版 v1.4.70，还包括本地 v1.4.71 的 NoMount Suite 命令兼容、同 ROM 可信原厂快照重新扫描、运行数据统一到 `/data/adb/ziyu`、首次完整重启迁移与清理已知旧目录，以及移除独立实验性 Zygisk 预加载模块。主模块名称统一为“字域字体管理器”。目录升级请完整重启一次。

这是本地 Debug 交付，未上传或正式发布。构建和包完整性检查随交付记录；未运行自动化测试，尚未进行本版手机验收。三种界面风格、大字号排版、真实报告导出、重启及反馈设备的 NoMount Suite 兼容仍待实测。新 ROM 或无完整可信快照时的底层 EROFS I/O 问题仍需设备日志定位。
