# ziyu v1.4.8 — 字体完整性与崩溃修复（本地 Debug 候选）

- Gemini 崩溃日志明确为 `/data/fonts/files/.../GoogleSans-Regular.ttf` 的 `verity bit was removed`，不是换行字形解析异常。Google 字体桥此前把不具备 fs-verity 的副本 bind 到受保护路径。本版先恢复账本中自有的旧替换，再为模块副本建立内核校验，保留目标字体的 PostScript 名称与 fontRevision；应用命名空间内的复制暂存也重新建立校验，并核对挂载后可见校验摘要。原始更新字体、系统验证代码、签名信任与全局策略不改动。文件系统或签名策略不允许建立校验时保留原字体，不能承诺该设备的受保护 Google 字体仍能替换。
- 通用字体部署复制动态字体后同样建立校验，启动挂载核对校验摘要；编译后的目标身份仍须满足 artifact 契约。保留来源变化、输出摘要、挂载验证和回滚条件。
- 字域 App 的日志是 Compose 无限高度测量异常，与 Gemini 独立。移除 Miuix/COUI 对话框包裹任意内容的额外纵向滚动层，保留内部列表自身滚动；共享底部弹层增加屏幕高度上限。旧日志的 R8 映射未提供，不能据编译通过宣称所有页面已验收。
- 移除新字体任务热挂载，全部离线生成并验证下一启动负载。旧热事务恢复及清理保留。当前字体在列表和详情里均可重新应用。
- KSU/SukiSU 确认本机 ksud 支持时，App 提供软重启及完整重启；Magisk/APatch/未知管理器完整重启。提供者重载和清理仍由原流程验证。
- 字体槽预检与发布共用转换后的 TrueType 整数控制点边界，修正紧曲线边界差异引起的假侧距不符；真正不兼容槽保留原厂。组合集合工作区绑定本次离线暂存负载，修正缺失工作区错误。Android lower 传播隔离改用正确 mount 参数，保留 mountinfo 验证。
- 主模块 ID 统一 `ziyu`，配套组件 `ziyu-font-preload`。升级先迁移已校验负载和配置，旧主模块与配套组件随后退役，旧卸载脚本保留而不执行，避免清除新模块资源。首次标识升级必须完整重启。旧内部状态名和字体别名前缀为恢复及来源溯源保留。
- 用户可设置字体、生成组合字体、导入目录、模块备份及报告的存放位置。保存只写待生效指针；下一次完整启动在共享存储就绪后复制、回读 SHA-256，并检查源/目标变化后提交，原文件保留。App 私有收藏/Studio 设置仍留在应用数据；手动完整备份由文件选择器选择位置。
- 完整备份改用 `common/full_backup.sh`，修复旧工具路径及实际包名暂存目录校验。复制失败不静默遗漏；导出暂存文件归还 App UID 并恢复 SELinux 标签。恢复失败验证回滚，回滚未完成时保留副本，兼容旧归档类型。
- 图片背景支持 PNG/JPEG/WebP/GIF/BMP 与本机可解码的 HEIF/AVIF，输入最大 32 MB，长边最多 2048 像素，动图为静态画面；三个主题跟随明暗覆盖，完整备份包含图片本身。
- ROM 比较基准改为 PID 1 系统 build 文件字段，避免全局 build 属性被 Root 改写时推断 OTA。迁移旧属性推断且未准备新负载的自有保护；保留真正基准变化、开机循环和外部停用保护。诊断补充保护状态及用户存储指针。历史 OTA 标签不能证明用户实际进行了 OTA。

## 证据与限制

六份诊断包含多个版本，其中 20261021-173819 是 v1.1.15，不能作为本版验收。两份用户字体只读检查未发现缺失组件、gvar 点数不匹配，所查字体表可解析；新崩溃栈已把本次 Gemini 故障定位到完整性契约。IOS_VF 的 U+000A 空轮廓/1000 字宽、另一字体的段落分隔映射均未擅改，也不冻结可变轴。

Android 对受保护字体还会核对修订号与 PostScript 名称，不能仅添加 verity 标志。依据 [AOSP Typeface.cpp](https://android.googlesource.com/platform/frameworks/base/+/master/libs/hwui/jni/Typeface.cpp)；Linux fs-verity ioctl 参数依据 Android NDK 的 UAPI 定义，代码为项目自有实现。没有关闭、绕过或 Hook 系统断言。

本版执行语法、Android/原生编译、签名及打包一致性检查；没有运行项目行为测试，也没有手机安装、刷入、重启、Gemini 换行、目录迁移或备份恢复实测，不宣称已测得加速或完成设备验收。受强制排除阻止 Zygisk 回调、OEM 独立字体加载和不支持 fs-verity 的文件系统限制，不能保证所有应用字体覆盖。
