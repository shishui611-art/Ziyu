# 字域 v1.5.16

本版减少开机阶段的进程创建，不改变字体应用与挂载流程：

- `post-fs-data`（zygote 启动前）与 `service` 阶段原本对 `common` 顶层约 253 个文件逐个执行 `chmod 0755`，每个文件都会启动一次 `chmod` 进程；现在改为一次批量 `chmod`，结果权限保持不变。
- 单次开机这两个阶段合计少启动约 500 个短命进程，减少启动早期的调度与 I/O 开销；可执行脚本仍为 0755，Python 数据文件随后仍恢复 0644。
- 挂载后端选择、开机保护、字体负载验证与回滚逻辑未改。

本次完成本地 Debug 构建与包完整性核对；未运行完整测试套件，未安装、刷入或重启手机，未做真机开机耗时对比。
