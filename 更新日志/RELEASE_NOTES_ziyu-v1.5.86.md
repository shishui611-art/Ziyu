# 字域 v1.5.86

以下为相对上一正式版 v1.5.69 的主要变化。

## 新增

- 设置的「字体工具」新增 Emoji 管理。可导入 TTF、OTF 或包含单份彩色 Emoji 字体的 ZIP，并单独预览、应用或恢复默认。文字字体与 Emoji 分别保存选择，可独立更换。
- 字体库支持自动列数和每行 1～4 列，直接导入和批量选择。卡片可打开应用、删除、字库预览和字体详情。
- 兼容的 FinaSU 内置 VFS 环境可以在字域重启弹窗选择「内核软重启」，「普通重启」也始终可选。

## 修复

- 修正组合字体准备时缺少运行依赖或原厂集合快照的问题，同时保留字体来源和生成结果校验。
- 修正普通重启已提交时可能误报命令超时的问题。软重启清理仅检查相关字体负载，清理未通过时保留待应用字体，并在首页提供普通重启。
- 修正 ColorOS 通用字体被整体缩小的问题。数字宽度适配仅用于允许替换的专用数字字体，保留可变字体的连续字重。

## 优化

- 管理器挂载并入自动模式。根据当前 Root 环境识别管理器内置后端或兼容元模块，挂载状态会区分等待重启、实际生效和失败。
- 字体库顶部控件随卡片一起滚动，导入以外的工具集中到设置。确认批量删除后卡片立即隐藏，由后台依次删除，失败项恢复显示。
- 诊断补充实际挂载后端、软重启清理和待应用字体记录。

包内 App 使用正式签名。FinaSU 更换新字体后的软重启、其他机型的挂载表现及酷安字库基准覆盖仍待真机验证。
