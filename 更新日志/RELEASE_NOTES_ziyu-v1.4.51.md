# 字域 v1.4.51 本地试用说明

本次先交付 Debug 包，未发布、未上传。相较 v1.4.50：

- 修正 SukiSU/NoMount 软重启窗口判断。ColorOS 的持久 Tango 翻译进程也使用 zygote 进程名，不能以 pidof zygote 判断管理器是否完成 stop。现在以 init 管理的主、辅 zygote 服务状态为准；仍要求管理器 post-stop 阶段、PID 1 命名空间、事务锁、字域规则精确匹配和清理验证。旧版本因此失败的事务可在下一次受控软重启重试；没有直接隐藏重启提示。
- 修正只替换单独 f、i 而遗漏 GSUB 连字目标的问题。组合引擎和最终原厂槽位均替换可追溯的拉丁连字。优先使用所选字体自带的连字，没有时用所选字母轮廓拼合；保留原厂 GSUB、glyph ID、其他语言及现有几何/输出契约。新引擎身份进入缓存键，重新生成后生效。
- 自动化减少重复执行：完整 runtime 安全工作流改为手动诊断入口，常规候选和正式发布仍运行完整源检查；独立安全/更新工作流不再重复构建 Android；旧 Beta 专项仅在其实际相关文件变化时自动运行。Shell 语法检查只遍历 Git 源码，不扫描 dist 和 Gradle 生成副本。

本地编译、包完整性与针对性验证结果见交付目录记录。尚未安装到手机，软重启激活、实际应用 fi 显示和视觉效果由本轮试用确认；不以源码改动推断设备性能提升。正式发布需等用户试用反馈。
