# 字域 v1.4.27（本地 Debug 候选）

基于 v1.4.26，增加内置 HarfBuzz 15.0.0 的 ARM64 可变字重实例器。支持的 TrueType、CFF2 在普通字体、组合的中文/英文/数字准备和 HyperOS 静态目标中优先使用原生路径；SVG 表会先核对字节一致。少量 gvar 数据损坏时，只在临时副本中移除有问题的字形变化记录并尝试原生处理，提示该字保留默认轮廓。其他格式或原生结果不符合检查时沿用 FontTools 和原有兼容路径。缓存身份绑定引擎、修复与字体面选择代码。

修复集合中可变字体面仅按默认字重选取，以及仅传入字重时可变轴仍使用默认值的问题。原厂集合生成报告实际逐面、合并和验证阶段，组合任务显示子任务实际阶段；状态查询避免反复改写没有变化的模块描述。

安全与维护新增 Zygisk 配套预加载组件状态和控制：只在框架实际执行回调时运行，不自动开启 Zygisk 或修改排除名单。App 提供 LSPosed 入口，可由用户选择目标 App，对系统 WebView 中允许脚本的网页文字使用当前系统字体；图标、代码、画布及独立内核有各自限制。

电脑同条件单次实测：iOS26PingFangUISC、700 字重的完整组合准备由 FontTools 43.154 秒变为 Windows HarfBuzz 桥 2.840 秒；全量字符映射、字形顺序、字宽及 92 个抽样轮廓通过对照。损坏 gvar 的字体在原生输出缺失轮廓时成功回退，保留原有恢复提醒。手机和整次应用尚未测量。

保留源变化、字形及输出校验、原厂契约、挂载验证与回滚。测试和签名范围以交付说明为准；未提供正式签名，交付为本地 Debug，不自动安装、刷入或上传。手机显示、耗时和 ROM 兼容需真机验收。
