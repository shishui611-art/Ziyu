# 字域 v1.4.101 本地 Debug

相对 v1.4.100：

- 首页标题、预览文字、底栏和设置名称可以自己改，留空恢复默认。
- 首页字体卡片可以换背景、加贴纸；位置、大小、角度、透明度和模糊都能调整。
- 浅色、深色主题可以分别保存卡片；导入和导出主题时一并保留图片、贴纸和自定义文字。
- 应用主题时可以选择是否使用主题中的文字。
- 清理未使用的辅助函数和主题加密导出代码，保留正在使用的字体兼容与迁移功能。
