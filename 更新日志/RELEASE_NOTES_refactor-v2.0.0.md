# 洛书 2.0.0 正式版

以 1.1.1 正式版及「无常驻测试2」为基础，不包含 Test10 的大范围重建路径。

## 全局粗细调节退场

移除首页全部风格中的全局粗细滑块、状态读取和设置写入。字体本身的多字重、可变字体及组合字体轴设置继续保留。升级仅在系统值仍等于洛书上次写入值、且存在原值备份时恢复旧值；其他来源的新设置不动。安装环境无法连接设置服务时，仅在首次开机有一次有界重试，不启动常驻进程。

## 刷写与任务页面

- Root 管理器安装输出分为环境与迁移、原厂字体扫描、模块与 App 安装、字体挂载四个阶段；使用真实阶段，不伪造百分比或启动控制台动画进程。
- App 的字体刷写页面突出实际任务、进度与结果；进度平滑过渡，详情按需展开，原始日志可检索和复制。
- 任务说明提取可读错误信息，不直接用整行 JSON 作为主要说明；原始输出仍保留。
- 历史日志中的“正在处理”不再被算作当前活跃进程。失败不显示成功完成；准备好待重启不等于已生效。

## 无常驻与兼容修正

- 取消导入和应用确认时的独立预热，Google/主题字体处理保留有超时限制的开机单次任务，不再全天监视。
- 字体任务由进程监督器回收子孙进程；继续覆盖成功、失败、超时和取消路径。
- 含 SVG 字体保留 SVG、原始字形编号和轮廓，绕开依赖 lxml 的子集压缩，不删除用户字体数据。
- 保留原厂代码等宽字体，时钟专用数字字体单独判断；修正 ExtraBold/Bold 选择及可变字体到静态字重槽位的实例化。
- 对原厂清单已验证的 UI/时钟路径放宽旧文件名限制，不按通配符盲目扩展替换范围。

## 安装与边界

保持包名 `io.github.xgl34222220.luoshu`、模块 ID `LuoShu`、原正式签名和用户字体目录。模块 versionCode **70000**，App versionCode **7000001**。从 1.1.1 升级请覆盖刷入模块并覆盖安装 App，完整重启；已有字体负载按原迁移规则保留。需要新版字体生成修正时，在 App 中重新应用并按提示重启。

Root 管理器的「默认卸载模块」选项请保持关闭。曾安装过内部测试 App 的用户应安装本页正式 APK；不要为更新清除字体数据。

没有完成本版 HyperOS/ColorOS 真机全量验收，不保证所有字体首次一分钟内生成。Chrome 与体育彩票 App 的闪退/网络反馈未定位，不能标记为已修复。静态单字重来源不会凭空生成缺失粗细；SVG 可变字体仍保留可变数据；原厂 TTC/OTC 容器不错误压平成单面。开机单次处理结束后，不再持续替换 Google 应用新下载的字体。
