# 字域 v1.4.38（本地 Debug 候选）

- 字体槽兼容和 TrueType 原厂集合增加静态字形原生批处理：解码、复合字形分解及缩放在 C++ 中完成，复用同一供体、同一 UPEM 的结果。原生字形缓存与现有轮廓模板共享 64 MiB 预算；小槽位、TTC 供体、点匹配复合字形等仍使用现有路径。
- 通用编译器的原厂几何参考、已落盘输出验证、设备槽位实例化增加 HarfBuzz 原生优先；已修改的内存字体继续从实际内存表验证，避免读取未修改的源文件。
- Google 字体兼容可在一次原生操作中完成字符裁剪与选轴；目标仍为可变字体时保留轴。字体名称、字重、原子保存及 /data/fonts 的 fs-verity 封装仍沿用既有流程。
- CFF2 导出 TTF 时优先原生冻结默认轴，后续曲线转换与排版校验保留。CFF/CFF2 曲线转换和原厂排版契约发布尚未整体原生化，不声称全流程原生。
- Google 字体无需裁剪或改轴时直接沿用来源，避免不必要的原生进程、哈希与临时副本；原生字形缓存预算不足时直接保留既有处理路径，避免先生成再丢弃。
- 修正原生路径处理重合闭合控制点时的轮廓边界情况。源变化、取消、输出验证、原厂字形映射、缺字回退、挂载验证和回滚条件保留；旧 revision 2/4/5 激活负载仍可验证。

## 本次验证

32 项专项/回归测试及通用编译器检查通过。同一静态供体与简繁原厂槽位的单进程桌面对照，总计 90.61 秒 → 70.36 秒，减少约 22.3%；44,278 个输出字形的轮廓、字宽、映射及全部字体表一致，完整字体文件也逐字节一致。原生缓存复用一次，约 13.79 MiB。详细结果见交付目录的 validation-summary.json。原生新增路径专项、原实例器与集合编译回归在电脑上执行；实际简繁中文槽位逐字比较轮廓、字符映射、字宽及原厂保留表。Android ARM64 二进制由相同源码编译；在已连接手机的独立临时目录执行原生字形缓存、变轴实例化、字符裁剪，结果与电脑版逐字节一致，临时文件已清理。另检查来源、打包权限、APK 签名与内置 APK 一致性。

完整槽位耗时比较使用相同 C++ 源码的 Windows 构建，不能推断手机完整应用耗时。未安装到手机、刷入模块、切换字体或重启；手机字体显示与速度仍待验收。没有上传或发布。
