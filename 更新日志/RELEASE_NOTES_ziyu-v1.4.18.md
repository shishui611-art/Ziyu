# ziyu v1.4.18 — 组合结果对话框样式统一与通知点击回主页（本地 Debug 候选）

本版修正两处用户可见的界面/导航问题，不修改字体生成、挂载、校验与回滚逻辑。

## 修复

- **组合字体结果对话框样式不统一**：生成组合字体后的结果对话框此前直接使用 Material 的 `AlertDialog` 与 `TextButton`。在 Miuix、COUI 主题下，它与其余页面使用的对话框不同，三个操作（「应用并重启」「应用，稍后重启」「仅保存」）渲染成纯文字，看起来不像按钮。现在：
  - 对话框改用项目统一入口 `ZiyuAlertDialog`（按 MATERIAL / MIUIX / COUI 分派到底层设计系统）；
  - 标题、正文、输入框分别改用 `ZiyuText`、`ZiyuOutlinedTextField`；
  - 三个操作按固定层级排列为全宽按钮：主操作填充按钮「应用并重启」、次操作描边按钮「应用，稍后重启」、文字按钮「仅保存」；
  - 同一文件里的「重启应用字体」选择（完整重启 / KernelSU 软重启 / 稍后）与「N 秒后完整重启」回退对话框也统一为相同按钮层级与全宽布局。
- **实时活动/通知点击跳到日志页**：字体任务通知与实时活动（流体云）的点击 `PendingIntent` 此前带 `EXTRA_OPEN_TASK_CENTER=true`，打开 App 会直接进入任务中心/日志页。现在改为打开主页；任务中心仍可从主页入口进入。原生导入任务的通知行为未改动。

## 未改变

- 组合字体生成流程、预览来源、保存与应用逻辑、重启选择时机均不变；
- 字体集合编译、挂载方式、来源检查、输出校验、逐面证明与回滚条件不变；
- 原生预加载、挂载提供者与开机/OTA 保护逻辑不变。

## 验证范围

- 已完成 Android Debug 编译与包完整性检查（包名、版本、签名、模块清单、内外 APK SHA-256 一致、ZIP CRC 与大小）。
- **未**在手机安装、刷入、重启，未对三主题下的对话框外观、按钮层级、输入框样式、通知/实时活动点击跳转做真机视觉与交互验收。
