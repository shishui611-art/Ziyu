# 字域 v1.5.90

- 修复模块覆盖更新后执行软重启触发 `nomount-provider-owned-rule-cleanup-unconfirmed` 失败的问题：兼容解析内核 NoMount 对已替换模块旧路径附加的 ` (deleted)` 标记，并修复失败分支残留临时计划文件与回滚尝试重新添加已删 inode 的问题。
- 恢复软重启正常进入发布与 `pid_wrap` 流程，避免因 `post-fs-data` 中止导致 NoMount 跳过挂载、回退自建 941 MB ext4 镜像，以及高 PID 引发 ColorOS `zygote reboot by netd` 二次重启。
- 优化软重启清理与验证耗时：将 NoMount 规则清理期间每条规则 2 次 Python 回读改为删除后单次全量回读校验（保留全部白名单与回滚条件）；同一次启动内 `boot-completed` 与 `device_font_load_verify.sh` 在 `boot_id` 与负载清单哈希未变化且已通过 `service` 验证时复用当次验证报告，避免重复执行 3 遍全量 SHA-256 核验。
- 完善模块刷写与“操作”入口的内置 App 覆盖更新流程：在存在待更新标记时，点击模块“操作”按钮可先触发内置 App 覆盖安装再启动；刷写与操作入口遇证书签名不一致时直接显示明确提示，不再误报为“开机自动补装”。
- 包含 `v1.5.89` 的主题商店升级、v6 动态壁纸、4 套内置图标、单图/ZIP 图标包桌面快捷方式及底部导航栏图标自定义。

本轮改动为本地 Debug 签名构建、语法与打包完整性核验，手机软重启实测与实际耗时对比待验证。
