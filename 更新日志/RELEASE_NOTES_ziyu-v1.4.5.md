# 字域 v1.4.5 — 本地 Debug 字体生成优化候选

## 本次优化

字体生成时，同一字体面内的相同来源字形在安全预检与轮廓生成之间复用原始边界；相同来源字形映射到多个目标槽时也可复用，空轮廓按同样规则处理。缓存仅在单次字体面调用期间保留，随本次调用结束释放，不跨来源、字体面或切换任务。会暂时保存本次已计算字形的边界元组，未新增持久缓存、后台服务或等待。

目标的缩放、横向/纵向度量、复合字形依赖与变量字体约束仍逐项检查，未省略生成后的原厂契约核验、来源变化检查、输出内容验证、挂载验证和事务回滚。字符角色计数合并为一次 cmap 遍历；来源大小限制使用同一次身份读取中的大小，保留符号链接限制及后续身份复核。

## 包含的挂载与兼容修改

保留 v1.4.4 的自动挂载回退：自动模式优先可用元模块或管理器内置挂载；提供者不可用或验证失败时按已有条件尝试自挂载。无法识别 Root 管理器时明确选择字域 Magic Mount / bind，保留 unknown 身份。刷入时准备策略，完整重启后由启动 hook 执行，核对 PID 1 内容和路由，失败回滚。用户手动挂载选择与开机保护继续保留。

包含 v1.4.3 的静态字体原厂字符映射保留候选及其限制。本次优化不修改应用隔离设置、不增加 Zygisk 依赖；不能保证所有被撤销挂载的应用均不出现方框。未知管理器仍需要可用 Root、启动入口和挂载权限。

## 构建与验证范围

版本 v1.4.5 / 14005。构建本次可安装 Debug APK 与内置同一 APK 的模块 ZIP；核对语法/导入、Android 编译、签名、包名版本、独立和内置 APK 的 SHA-256、模块清单及 ZIP 完整性。未新增或运行行为测试，未安装到手机、刷入、上传或发布。

没有本版设备显示、启动兼容或同条件耗时测量结果。源码减少重复操作不等于已证明实际提速，也不作为方框问题已彻底解决的依据。
