# 字域 v1.5.57

## 修改

- 槽位发现继续覆盖设备上可识别的字体位置，但发布扩展只从当前 ROM 清单中的必要系统字体组挑选。主题装饰字体、其它语言回退字体和锁屏时钟默认保留。
- 恢复严格扩展检查：需要可信原厂字体；源字体须覆盖原厂文字字符、变体和复杂文字排版要求，并保留原厂连续变化轴范围。检查失败时该位置继续使用原厂字体。
- 删除框架软重启的主页选项、App 命令、独立运行脚本和专用状态。仅保留普通重启与 KernelSU 软重启。
- KernelSU 软重启保留停机后的有限 PID 准备。在没有 `CONFIG_PID_NS` 的内核上，不再调用不受支持的 PID namespace 进入参数；namespace 句柄存在时仍核对其一致性。

## 验收说明

- 16 项原厂快照和槽位策略回归检查通过；修改过的 Shell 文件语法检查通过。
- 四种 ABI 的 PID 工具已使用 Android NDK 重建，构建收据核验通过。
- Debug APK 编译成功；模块 ZIP CRC、载荷清单、包名、版本、签名及 ZIP 内 APK SHA-256 与独立 APK 一致性均已核对。
- PID 工具不会修改已运行进程的 PPID，也不保证后续 PID 达到指定数值。
- 尚未在手机安装 App、刷入模块或执行软重启；槽位数量、数字字体路由和 PID 准备仍待设备验收。
