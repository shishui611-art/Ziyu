# 字域 1.4.62（本地 Debug）

本版将按字体启用的防裁切适配与主页粗细入口调整一并交付。基于当前本地 1.4.60 及本轮主页改动；GitHub main 核对为 1.4.58，本次不提交、推送或发布。

## 防裁切

- 在字体库打开某款字体详情，开启“自动防裁切（ColorOS）”，再重新应用这款字体。默认关闭，避免未经用户选择改变现有字形大小。关闭后重新应用可恢复原比例。
- 根据源字体实际普通文字边界及可信原厂字体面的 hhea/typo 行框测量；同一目标面里的整套替换字形使用同一等比缩放和基线偏移，已完整落入行框时不变。不会按固定百分比缩小每款字体，也不会逐字挤压或统一扩大原厂行高。
- 校正实际进入 ColorOS 单字体槽与中文集合逐面编译。TrueType 核对生成轮廓头，CFF/CFF2 核对输出曲线边界；越界不提交。原厂字符映射、字形编号、布局表、行高和竖排原点仍按原契约验证。
- 当前面向普通静态字体、已保存的静态组合。未静态化的可变字体可先在工作室保存选轴结果；不支持的来源/设备或无可信快照时给出说明并保留现有字体，不能跳过适配后假报成功。专用/未覆盖字形按既有规则保留原厂。
- 按字体保存开关，模块升级保留偏好；具体测量及变换记录进入字体生成报告/证明。缓存绑定开关与实现，关闭后重应用不会误取之前的缩小结果。字体库预览仍为源字体，不代表已生成的适配结果。
- 只在需要变换的路径使用已有 FontTools 几何转换，未变换路径仍可使用现有原生缓存；全字形边界核对存在计算开销，不宣称手机提速。

## 主页粗细

- 删除三套主题共用的主页粗细滑块，改为提醒前往手机系统设置。字号、DPI 和“默认数值”的应用与回滚不再写入系统粗细，不把粗细归零。
- 移除全局粗细配置桥；旧客户端的粗细写入请求拒绝执行。系统粗细在其他位置改变，不再阻止无关的字号/DPI 调整；其自身的用户、旧值比较、回读及失败回滚保留。
- 原有粗细不会因升级强制清零。字体工作室的选轴和多字重功能继续保留，本地 1.4.59/1.4.60 的其他修正保留。

## 验证范围

本次仅 Android Debug 编译、Shell/Python 语法与 APK/模块 ZIP 完整性核对；检查包名、版本、现有 Debug 签名、独立/内置 APK SHA-256、当前模块清单及新增防裁切运行文件。未添加或运行行为/性能测试，未安装、刷入、重启或上传。

用户截图来自美团，但当前字体名称和源文件尚未取得，无法在本机复现该页面。新开关、具体字体的缩放幅度、各 App 固定高度控件及美团实际效果仍待手机验收；不会将包构建成功写成实际裁切已修复。
