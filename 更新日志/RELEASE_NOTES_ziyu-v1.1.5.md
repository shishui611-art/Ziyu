# 字域 1.1.5 本地 Debug

## 更新迁移

- 直接读取旧模块的 `.luoshu-payload`，避免安装命名空间只能映射部分分区时丢失字体。
- 将物理别名使用的 `.font` 锚点纳入负载识别；已生成组合迁移不要求旧源字体配方。
- 清单存在时检查文件完整性与 SHA256；活动负载无法迁移则中止更新并显示原因，保留原模块，不静默恢复原厂。
- 兼容旧版 CRC/大小清单，仅将迁移后的新副本规范为 SHA256；保留设备额外 OEM 分区和通用引擎的隐藏部署、动态字体文件。
- 删除刷写前改写旧模块 schema 和提前承诺“保留成功”的逻辑；成功复制以后才提示继承。

## 挂载诊断

- 修正 `/proc/1/mountinfo` 文件大小为 0 时被误判为空的问题，按实际内容验证主命名空间。
- 修正 Android mksh 的任务字段分隔兼容问题，以及 Android awk 的警告合并语法。
- Hybrid 分别报告配置缺失、非纯 VFS 路由、模块排除、运行文件或接口不可用等原因。
- 安装终端使用共享 Root 检测，区分 KernelSU 与有明确标识的 SukiSU Ultra。
- Meta 偏好不等于实际 Meta 已生效；缺少安全单模块卸载接口的 Overlay/Magic 模式继续使用自挂载。

模块 ID 与兼容数据路径仍为 `LuoShu`。保留 1.1.4 的组合保存与真实预览、任务终止与回退、日志已阅/清除和挂载偏好功能。

本次仅提供本地测试包；没有自动刷写、重启或发布 GitHub。实机验收由用户完成。
