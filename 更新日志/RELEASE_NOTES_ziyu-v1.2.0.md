# 字域 1.2.0

## 从 1.0.0 到 1.2.0

- **字体组合更稳定。** 连续生成不同字重时更能保持原先选择的字体；英文、数字和含 SVG 字形的字体也得到兼容修正。
- **更方便使用原厂字体。** 可以把手机上的原厂字体导入字体库，再搭配中文、英文和数字字体使用。
- **挂载结果更清楚。** 在 App 中可以看到实际使用的挂载模块、挂载方式，以及成功或失败的原因；刷入时只显示简明结果。
- **挂载失败时会继续尝试恢复。** 外部挂载模块不可用或验证不通过时，字域会按设备情况尝试自己的挂载方式，并保留具体结果供查看。
- **首页和设置提醒保持一致。** 能区分系统默认字体无需挂载、字体仍待确认和挂载失败等状态；需要关注的兼容提醒会显示在设置中。
- **可以在 App 内更新模块。** 更新下载的是完整可刷入 ZIP，App 随模块一起更新，不需要单独下载 APK。
- **发布包更简单。** 正式版和 Debug 版都只提供模块 ZIP 与校验文件，ZIP 内已包含对应 App。
- **应用包名改为仓库对应名称。** 从旧包更新时，Android 会把新版识别为新 App；请重新授予 Root，旧 App 的个人设置不会自动迁移，建议先导出备份。

## 更新网络说明

App 内更新目前直接访问 GitHub。中国大陆网络能否连接取决于当地网络线路；在接入国内稳定发布源并完成无代理实测前，不能保证无需代理。

从旧版升级时，1.2.0 使用仓库对应的新应用包名 `io.github.shishui611_art.ziyu`，Android 会将它作为新应用安装。请重新授予 Root 权限；旧 App 的个人设置不会自动迁移，建议先导出备份。
