# 字域 1.1.14 Debug

- 挂载改为自动选择：可用的外部提供者优先；确认没有提供者时才通过唯一的 OverlayFS / bind 实现自挂载。
- 字体负载直接读取私有目录，取消加载辅助脚本时创建的 bind 视图；外部模式在早期启动发布普通文件目录。
- 同一次启动固定提供者身份和后端。外部接管失败不切换为自挂载；状态未知时停止注入并记录原因。
- 尊重外来的跳过标志和禁用状态；卸载失败保留本模块的清理记录。
- NoMount 使用提供者的标准扫描目录，不创建私有规则；旧规则清理逻辑保留用于升级兼容。
- App 的挂载设置改为自动挂载状态展示，旧设置命令统一转换为 `auto`。
- 模块与 App 版本号为 1.1.14，versionCode 为 11014。本轮 Debug 交付以最新带时间标记的目录为准；尚未安装到设备验收。

具体阶段和验证方式见 [当前字体挂载流程](docs/MOUNT_FLOW.md)。
