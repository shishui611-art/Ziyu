# 字域 v1.5.29

本版修复“重启后仍显示待重启验证”、系统字体导出卡住，并给字库预览加上真实缺字标注。

## 1. 待重启误报

- 状态脚本把 backend 验证模式识别为 verified；
- 后端本次启动 `mounted + verified` 时忽略过期的 `text_reboot_required.conf`；
- `boot-completed.sh` 在确认后端通过后删除过期标记，避免它还拦截下一次应用。

## 2. 系统字体导出（折中 + 后台）

- 默认只导出每个角色的 Regular 一个字重（中文/英文/数字各 1 个文件），首次约 2~3 分钟；已有条目缓存秒回。
- 改成 `start / status` 后台任务：App 点按钮后立即返回，显示“正在后台导出”，每 3 秒轮询，完成后自动刷新字体库。
- 只有当前是系统默认字体时才走 1 秒快速复制；已应用字体时走原厂导出，避免把替换后的字体当成原厂。
- 快速路径会清理旧的多字重残留文件。
- 字体库入口从小字改成“添加系统字体”按钮；设置里的系统字体导入卡片已删除。

## 3. 字库预览：缺字标注

- 预览继续用 `Typeface` + Android 原生 Skia/HarfBuzz 排版；
- 新增 `Paint.hasGlyph()` 逐字检查：字体没有该码位时，预览右下角显示“缺字 N”小标签。
- 说明：Android 在缺字时会静默回退到系统字体，所以以前“看起来缺字”可能只是回退显示；现在能直接区分“字体真缺字”和“模块显示问题”。
- 可变字体仍按变化轴设置渲染；TTC 仍按 Android 默认 face 渲染（后续可按 conf 指定 face 导出）。

## 4. 其他

- “保留原厂字体”规则页接入设备槽位分类（中/英/数）；
- 首页恢复“立即软重启”（临时 Root 模式下先弹 KernelSU 软重启说明）；
- 修复后台导出进程 pid/状态判断、旧文件残留等 bug。

## 限制

- 未做手机验收；状态显示、后台导出耗时、缺字标注、预览回退提示需刷入后验证。
- 缺字标注基于 `Paint.hasGlyph`（系统 Skia 结果），不等同于完整 cmap 审计；TTC 仍只预览 face 0。
