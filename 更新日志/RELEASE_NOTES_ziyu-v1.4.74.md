# 字域 v1.4.74 本地 Debug 说明

刷入时直接选择 Root 类型，不必等进入 App 再手动开启：

- 音量上键（+）：普通 Root。
- 音量下键（-）：临时 Root，适用于完整重启会丢失 Root 的情况。

首次安装和升级都会显示选择。30 秒未按键则保留原设置，首次安装默认普通 Root；Recovery 或当前安装环境无法读取音量键时，直接使用这个保留值。选择写入模块现有配置，App 同步读取；KernelSU 系列可在「设置 → 安全与维护 → KernelSU 软重启」继续修改。它不切换 Root 管理器，不自动执行重启。

临时 Root 的软重启仍需 KernelSU / SukiSU Ultra 和实际可用的 `ksud soft-reboot`。Magisk、APatch 或未识别的管理器不因此获得内置软重启支持；需要使用各自支持的模块加载方式。真实 late-load 会话继续自动识别。跨旧命名目录升级时仍需完整重启一次，再重新获取临时 Root 并加载模块；安装完成页会明确提示。

相较上一正式版 v1.4.70，本包还包含 v1.4.71–73 的 NoMount Suite 兼容、同 ROM 可信快照扫描、数据目录收纳和旧残留清理、独立实验组件退役、日志导出按钮、重启确认及 ziyu 命名整理。

本次为本地可安装 Debug 包。源码语法、Android 编译、实际 APK 版本与签名、模块清单和独立/内置 APK 一致性检查见交付记录。未运行自动化测试，尚未在手机刷入验证音量键读取、普通/临时 Root 切换、升级设置保留或重启；未安装到手机、上传 GitHub 或正式发布。
