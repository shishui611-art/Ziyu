# 字域 v1.4.71 本地 Debug 说明

相较上一正式版 v1.4.70：

- 修复新 NoMount Suite 的识别和规则命令兼容；原来的字体来源校验、挂载验证与失败回滚继续保留。
- 同一系统版本下，手动扫描可以重新核验可信原厂快照，不再必须经过设备可能拒绝的独立只读挂载。系统变化、快照缺损或哈希不符时继续要求真实原厂来源。
- 字域自己的运行数据统一放进 `/data/adb/ziyu`；升级保留并迁移恢复记录及用户文件。当前开机仍在使用的旧目录在完整重启后清理，未识别或仍占用的内容会保留并记入 `logs/adb-storage.log`。
- 移除独立的实验性 Zygisk 字体预加载模块和设置入口，旧自有组件随升级退役。Root 管理器里主模块名称为“字域字体管理器”。

本次目录升级请完整重启一次。`/data/adb/modules/ziyu` 和管理器规定的启动入口仍使用管理器要求的位置，共享存储字体库仍在用户选择的位置。

这是本地 Debug 交付，不是正式发布；编译和打包检查不替代手机验收。未运行自动化测试，反馈设备的 NoMount Suite 1.85、首次升级、重启、字体显示与恢复仍待实测。无同 ROM 可信快照时的底层 EROFS I/O 问题尚未获得设备级验证。
