# 字域 v1.4.89 本地 Debug

相较本地 v1.4.88：

- 取消防裁切固定默认字重的做法。TrueType 可变字体适配时保留原字重轴与范围，仍可连续调节粗细。
- 按整个可变范围计算统一缩放，保持字形比例与基线；文字可能略小。
- 同一来源共用测量结果，相同原厂行框复用输出，生成后的完整结果继续缓存。
- 不支持的字体不转换为固定字重，当前字体保持原样。

当前实现针对 TrueType/glyf 可变字体及其 TTC 集合，保留来源字面索引；原厂目标为集合时要求索引兼容，单来源字面可填充原厂集合。CFF2、对齐点组件及部分布局/位图格式仍不支持，不会转成固定字重。保留来源字符映射，不宣称保留原厂字符映射。极少数字形会使保守适配缩小较多；固定高度或应用自带字体的界面仍需实测。

此为 Debug 包。编译、打包和手机验收分别记录，未运行测试套件；未安装、刷入或发布，实际显示、连续字重操作和耗时尚待手机验证。
