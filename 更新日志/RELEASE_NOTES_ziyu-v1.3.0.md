# 字域 1.3.0 正式版

字域 v1.3.0 / versionCode 13000。相较 v1.2.0，本版汇总了后续 1.2.x 中的挂载、字体验证与性能改进。

## 新增

- 挂载模式由用户明确选择：元模块自动挂载、字域自挂载、Magic Mount、OverlayFS。选择会保留在模块升级中；切换后可选择立即重启验证或稍后处理。
- 挂载详情显示本次启动的 Root 管理器、元模块/外部提供者及版本、实际挂载实现、字体路由验证与具体原因。
- 对本次启动中已验证的物理自挂载，符合模式和字体负载条件时支持自定义字体间热切换。已打开界面仍可能有字体缓存；支持时 App 可在用户确认后请求 KernelSU / SukiSU Ultra 软重启。
- 字体目标可按验证证据报告成功、部分应用警告或失败；设置页可忽略已知兼容警告，同时保留原始诊断记录。
- 增加用户可直接运行的 `common/font_partition_compat_report.sh`，只读采集设备分区、字体 XML 路由、挂载及 OverlayFS 诊断，并在脚本旁生成日志。
- 正式签名配置齐全的 Debug 构建可用相同 applicationId 和证书覆盖正式 App；未配置正式签名的本地 Debug 保持独立 `.debug` 包。

## 修复

- 修复模块刷入/升级流程把用户选择的自挂载偏好改回自动模式的问题。
- 修复挂载成功、字体路径加载和“等待重启”状态混用导致的错误提示；挂载、字体文件路由和进程缓存现在作为不同证据呈现。
- 增强 ColorOS SysFont-Hans/Hant 经 `/data/format_unclear/font` 到系统字体槽的原厂桥接链接核验，降低真实字体已路由却仍显示待确认的情况。
- 修复部分 OverlayFS 参数、F2FS lower、长路径 loop 镜像及别名目标冲突时的兼容处理；只有字域自挂载可按安全规则改走 bind，显式 OverlayFS 不会切换后端。
- 修复字体任务失败、后续任务提交、热切换回滚、旧挂载代清理和软重启状态核验中的多项事务边界问题；日志和 App 结果区分等待、部分应用和失败。
- 修复 TTC/字体导入、部分可变字体字形实例化及字体路径诊断中已定位的兼容问题。

## 优化

- 复用同一任务内的字体族/字重扫描快照和文件身份，减少重复遍历，同时在源文件变化时仍拒绝提交。
- 通过稳定化字体库存缓存身份、复用字体原始表并直接写入少量变化表，降低重复 JSON、SFNT 表读取与整体字体序列化工作。
- 合并部分 App Root 状态读取，后台化字体列表筛选排序和任务状态读取，减少重复进程调用及界面阻塞。
- 改进诊断日志覆盖：补充挂载偏好、OverlayFS 参数/错误、实际字体路由、桥接链接、进程映射、热切换回滚和软重启清理证据。

## 与 v1.2.0 的行为差异

v1.2.0 已包含字体组合、原厂字体导入、挂载结果说明、App 内模块更新和单 ZIP 发布。本版保留这些功能，并进一步把挂载方式选择交还用户，区分外部提供者和字域自挂载；支持有限条件下直接热切换；把部分槽位警告与整体应用失败分开；提供更详细的设备兼容和加载路径证据。模块更新仍下载完整模块 ZIP，App 随 ZIP 内置，不需要单独安装 APK 来更新模块。

## 验证状态

正式 Release 由 GitHub Actions 执行源码检查、Android Lint/单元测试、固定签名、APK/模块 ZIP 一致性及发布门禁。设备验证矩阵仍为待测；历史设备诊断和自动化通过不代替 v1.3.0 在各机型上的完整真机验收。实际发布状态和附件以 [`ziyu-v1.3.0`](https://github.com/shishui611-art/Ziyu/releases/tag/ziyu-v1.3.0) 正式 Release 页面为准。
