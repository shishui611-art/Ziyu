# 字域 v1.5.41

## 槽位问题定位工具

1. **扩展数量限制（二分定位）**
   `config/tools/slot-coverage-limit.conf`：

   ```
   limit=50
   ```

   只扩展计划里的前 N 个槽位（顺序固定、可重复）。逐步调整 N 并重启，即可二分出
   “加到第几个槽位开始卡开机”。

2. **逐槽位日志**
   `logs/slot-coverage.log` 会记录本次真正扩展的每个槽位：

   ```
   [SLOT-COVERAGE] add=NotoSerif-Bold.ttf
   ...
   ```

   开机卡住后从日志最后几行即可看到最后加入的槽位。

3. 默认行为不变：未创建 limit 文件时扩展全部安全槽位；`enabled=0` 可整体关闭。

## 建议二分流程

1. 安全页开启“全量槽位覆盖（100+）”；
2. 设置 `limit=50` → 应用字体 → 重启；
3. 能开机 → 改 `limit=100`；不能开机 → 改 `limit=25`；
4. 重复直到相邻两个 N 之间只差 1 个槽位，最后对照 `slot-coverage.log` 的 `add=` 记录即可锁定具体槽位。
