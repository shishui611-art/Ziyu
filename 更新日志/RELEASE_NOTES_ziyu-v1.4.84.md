# 字域 v1.4.84 正式版更新

相较上一正式版 v1.4.70，这段时间累计完成了这些改进：

- **字体挂载兼容性更好。** 修复对新版 NoMount Suite 的识别与调用；原有字体来源检查、挂载验证和失败回滚仍会执行。原厂字体扫描会复用经过校验的同 ROM 快照；系统版本变化或快照不完整时，仍会要求重新扫描可靠的原厂字体。
- **修复部分 ColorOS 17 字体应用失败。** 使用 TTC 字体集合（例如本次反馈的 PingFang UI）时，兼容处理会保留完整集合和关联别名，不再因等待不会生成的重写文件而中断应用。
- **旧版升级迁移更可靠。** 修正读取旧模块字体状态时误向旧目录查找新版辅助脚本的问题，避免升级迁移被中断。
- **Hybrid Mount 兼容检查已校准。** 按当前字域模块名称检查规则和排除名单，避免旧模块名让兼容检查结果失真。
- **发布回归夹具依赖已补齐。** 通用字体部署与挂载检查使用完整的启动依赖，继续验证负载激活、挂载和失败回滚，并同步 Google 字体兼容检查中的模块 ID 与数据目录断言。后续字重输入前缀、启动保护、体检、诊断导出和切换夹具也按当前目录结构同步，保留原有行为断言，并检查当前 App 不再连接归档的旧版全局粗细控制。
- **发布校验已修正。** 清理历史发布测试夹具中的旧项目名，避免自动发布在检查版本信息时中断。
- **旧版本更新判断已修复。** 系列切换导致显示版本重置时，在线更新会继续按递增的安装编号识别新版本。
- **模块文件更集中。** 字域运行数据统一放在 `/data/adb/ziyu`，升级时迁移已知的旧版数据，并在完整重启后清理可确认属于旧版的残留。无法确认归属或仍在使用的文件会保留，避免误删其他模块内容。
- **Root 管理器里只显示一个字域模块。** 移除单独的实验性预加载组件，主模块统一显示为“字域字体管理器”；刷入时可选择普通 Root 或临时 Root，默认使用普通 Root。
- **模块的“打开 App”按钮更可靠。** 已安装字域时直接打开；尚未安装时先安装模块内的 App，再打开。
- **日常操作更清楚。** 日志页增加导出入口，软重启确认按钮更明确；字体搜索框为图标留出间距；安全体检和清理使用统一脚本入口。
- **字体预览和外观设置更灵活。** 可以保存自定义预览文字，也可以调整卡片透明度；透明卡片不再绘制造成内部矩形色块的投影。
- **通知兼容性修正。** Android 16.0 继续显示常规任务进度；只有系统报告支持对应功能的 Android 16.1 才会发送实时活动提升请求。

本版仍保留字体内容校验、系统挂载验证、异常回滚和旧数据兼容。设备与系统组合尚未覆盖所有 ROM；如遇到不能应用字体或开机后字体未生效，请从字域导出日志并附上机型、系统版本与 Root 管理器，便于定位。
