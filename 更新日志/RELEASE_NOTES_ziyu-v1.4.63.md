# 字域 v1.4.63 本地 Debug

针对 v1.4.59 用户反馈的手动原厂字体扫描失败，修正当前工作副本中已确认的任务执行问题。包含本地 v1.4.59–v1.4.62 的状态同步、兼容生成、系统粗细提示与按字体防裁切改动；本次不上传 GitHub 或发布。

- 开机保护直接进入专用 Root 命令，避免扫描请求依赖无关字体库和挂载初始化。
- 扫描工作进程单独提交运行与最终结果，启动方不再覆盖终态。每次扫描有独立请求身份，旧进程不能覆盖重试任务。
- 重试只清理已确认停止的自有扫描及异常遗留计时文件；核对模块、任务、监督器和进程身份，运行中的任务继续复用，不杀未知进程或删除未知文件。并发请求串行处理启动和回收阶段，完整扫描在已有监督器限定的后台任务中运行。
- 已可信核验的默认字体恢复记录可直接完成 OTA 收尾，无需再次完整扫描。页面跟进用户发起的手动扫描，完成、失败分别展示；扫描失败保留保护和旧字体负载。诊断补充扫描日志、任务记录和退出证明。
- 不在普通字体切换中增加完整扫描，不删除 OTA 前置校验。现有可信原厂来源、来源变化、输出校验、挂载验证及回滚保留；不承诺未实测的速度变化。

## 验证范围

构建可安装 Debug APK 和内置同一 APK 的模块 ZIP，检查版本、签名、包清单、脚本语法和 APK 摘要一致性。不添加或运行行为/性能测试，不自动安装、刷入或上传。缺少反馈手机手动扫描失败时的关键日志，不能断言该设备的实际触发原因与本次修正完全一致；扫描、核验收尾及重新应用仍待手机验证。Debug 证书不能覆盖不同证书的正式 App。
