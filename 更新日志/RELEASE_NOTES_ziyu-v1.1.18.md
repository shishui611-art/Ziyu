# 字域 v1.1.18

- 修复挂载状态 schema v3 未被 App、字体加载验证、字体负载复用和 Universal 运行验证读取的问题，避免已写入本次启动的挂载结果被误报为待确认。
- 刷写终端明确区分系统默认字体下的“无需挂载”、自定义字体下的“待完整重启”及显式排除下的“已跳过”。
- 启动挂载日志明确记录选择后端、生效后端、元模块、实现方式、路由验证、回退原因和失败原因。
- 安装文案与实际策略一致：外部提供者缺失、状态不明或验证失败时，会按策略尝试字域自挂载；显式排除仍会跳过。
- 设置页健康摘要与“需要关注”共用告警来源；待验证挂载状态会显示具体提醒，读取过程中不会显示误导性的空列表或健康结论。
- 精简刷写终端：只显示当前挂载状态与必要的重启提示；后端、实现方式和验证细节留在 App 挂载详情及运行日志。

本版本尚未安装到设备实测。
