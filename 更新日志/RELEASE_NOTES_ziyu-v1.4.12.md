# ziyu v1.4.12 — SukiSU 双主题样式适配（本地 Debug 候选）

按用户选择，将 SukiSU-Ultra 最新 main 的 Miuix 与 Material 3 Expressive 样式适配到字域现有对应主题，并保留 COUI。参考提交 `df84920b20a925fd1135530f6e403361ad494d7b`（上游提交时间 2026-10-24 北京时间），完整来源与许可见 THIRD_PARTY_NOTICES.md。

- Material 使用 MaterialExpressiveTheme 与 expressive motion scheme，8/12/18/24/32 dp 圆角体系；色调卡片与按压弹性缩放参考上游 TonalCard。按压使用原生 Card 自身交互源，保留启停、点击和取消行为。
- Material 悬浮导航开启玻璃时复用字域已有的透镜、拖动与高光实现，按当前 Material 配色呈现；关闭玻璃使用选中项展开标签的实体胶囊导航。悬浮关闭仍为常规 Material 导航，Miuix 与 COUI 原生导航保留。
- 调色增加表现力、彩虹、缤纷、单色、忠实和内容，与原有柔和、鲜艳、中性组成九种风格。Material/Miuix 支持新版 2025 和经典 2021 规则，按上游范围限制 2025：柔和、中性、鲜艳、表现力；其他变体回落经典规则并说明，不产生无效配色组合。
- 外观页增加真实调色器生成的浅深色预览及直接切换；预览不嵌套 App 主题或创建弹窗宿主、修改系统栏。增加上游樱花等 15 个颜色，保留六个原主题色和设置。Monet 取色开启时颜色选择保持停用，关闭后可选择固定颜色。新配色版本写入既有 DataStore，并纳入完整备份恢复。
- COUI 保留主题控制器和原生控件；原图片背景、纯黑、模糊、玻璃、悬浮、高刷开关继续可用。Material3 对齐上游 1.5.0-alpha28 的公开 Expressive API；Miuix 与 COUI 主题库保留现有版本，不整套升级上游构建链，也不引入管理器 Root/内核业务。低版本着色器检查及实体回退、现有裁剪和导航语义处理保留。共享 Material 组件库更新后的各主题实际表现仍待手机验收。
- 新增来源文档与 GPL 第 3 版许可证，模块打包清单包含许可证；APK 内新增 UI 代码随当前源码构建。字体、组合、挂载、预加载、本地显示缓存、备份事务与回滚代码不在本次主题适配中修改。
