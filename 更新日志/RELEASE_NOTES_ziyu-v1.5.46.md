# 字域 v1.5.46（本地 Debug）

本次是在 v1.5.45 开发版上的修正，尚未正式发布：

- 修正主题字体反复替换后无法还原的问题，恢复记录与备份独立保存，失败后可以重试。
- 恢复默认字体和卸载会先还原主题字体；未完成时保留备份并提示原因。
- 主题字体失败或部分完成时，不再一律提示成功，并保留还原入口。
- 扩展替换前核对原厂字库，缺字或不兼容的槽位保留原厂，避免只增加文件数量却丢失其他文字。
- 修正时钟开关与覆盖计划不一致的问题，切换设置后重新应用即可采用新设置。
- 修正 NoMount 软重启清理中断：停止系统后接着处理旧字体，再加载新字体；仅重启框架不能代替模块重载。
- 软重启后尝试降低新进程的编号，处理失败会保留原因；不会清空现有进程 PPID，也不保证通过任何检测。
- 软重启保留两次确认，页面直接显示操作结果。

兼容检查不固定可变字重，不逐字重建字形。缺少可信原厂快照或不兼容的格式继续保留原厂；现有异常负载需重新应用字体后再验证。系统主题服务另行改过的文件会保留现场与备份，需要核对日志后处理。

按本轮用户提供的交付规范生成 APK 与内置同一 APK 的模块 ZIP；编译与包完整性结果见交付目录的 DELIVERY.json。未运行功能测试或完成手机验收，未安装、刷入、重启或上传 GitHub。实现和待验证范围见 [主题字体恢复说明](../docs/THEME_FONT_RECOVERY.md)、[软重启适配说明](../docs/SOFT_REBOOT_v1.5.46.md)。
