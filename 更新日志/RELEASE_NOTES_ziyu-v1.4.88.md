# 字域 v1.4.88 本地 Debug

相较本地 v1.4.87：

- 字体对比优先显示样例，长名称单行显示，可展开查看。窄屏使用上下对比，预览文字和字重按需调整。
- 导入预览更简洁，文件详情与样本统计默认收起；只导入一个文件时不再显示翻页按钮。
- 导入完成只显示结果，失败时保留具体原因。
- 文件位置只显示一处路径，输入框与按钮之间保留间距。
- “字体应用范围”改为“字体替换设置”，需要填写路径的规则移到高级设置。
- 修复可变字体开启防裁切后应用失败：自动按字体默认字重生成临时样本，不再要求手动保存静态组合。原文件保留，防裁切下使用固定字重；关闭并重新应用可恢复原流程。文字可能略小。
- 同一批次的相同来源共用防裁切样本。再次应用时优先复用已生成的完整缓存；字体、系统或处理设置改变后才重新生成。首次仍需处理，实际耗时待手机实测。
- 将文案简短、不写设计说明、信息不重复等要求写入项目规范，后续界面继续遵循。

已读取手机 v1.4.87 的失败日志，确认本次失败来自可变字体被静态来源检查拒绝。新版编译与包完整性单独核对；尚未安装新版或在手机重新应用防裁切，其他 ROM、TTC 与固定字库挂载验收仍待完成。未运行测试套件，未自动安装、刷入或发布。
