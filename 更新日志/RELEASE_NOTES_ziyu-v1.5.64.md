# 字域 v1.5.64

本版修正正式版状态回归场景，并完整包含苹方 TTC 默认字体面修复。

## 修复

- 状态回归检查使用模块实际生成的待重启记录，核对选择字体与当前启动状态。
- 正式版源码检查按 `common/` 顶层文件对照清单，子目录文件继续逐项校验，避免已登记的槽位配置和 PID 回绕文件误报。
- ColorOS 应用静态 TTC 字体集合时，根据中文覆盖、原字体字重与样式选择默认字体面。修复苹方默认读取缺少“远”（U+8FDC）的港版字体面导致的粗细混杂。
- 保留 TTC 集合内全部字体面与原始数据、显式非零面索引路径及可变字体连续字重处理。
