# 字域 v1.5.50（本地 Debug）

相较上次交付的 v1.5.48（包含本轮 v1.5.49 修改）：

- 首页刷新图标打开菜单，可刷新状态或选择普通重启、内核软重启、框架软重启；重启保留两次确认。
- 内核软重启向 KSU 请求；框架软重启会短暂黑屏，挂载已准备的新字体、核验后启动 Android。失败时尝试恢复旧字体。
- 补齐框架事务从管理器挂载切换到临时自挂载的授权状态；失败恢复原状态，不更改保存的挂载偏好，也不遗留会阻碍下次开机的临时排除标记。
- 两种软重启共用有次数、时限和参数恢复检查的 PID 调整入口；不能清空已有 PPID，结果需要手机验证。
- 修复缺少原厂字体资料时扩展被全部跳过的问题，只在应用字体时按需获取指定原厂文件，开机与软重启不补扫。
- 首页统计实际使用的字体目录，不把旧发布目录的数量当作框架挂载后的数量。
- 主题商店暗色白字、浅色黑字，预览文字增加对应底色；主页简写“管理器挂载”。

更新后请重新应用一次字体，为框架路径生成完整性记录。旧版本准备、没有该记录的字体不会直接框架挂载。恢复系统默认字体、Universal/XML 负载暂用普通重启或内核软重启。

本轮仅完成源码编译和包完整性核验，未安装新版或执行任何重启。原厂资料获取、100+ 实际扩展数量、框架新字体挂载与回滚、两种软重启的进程编号效果、三种 UI 风格和深浅色外观均待手机验收，不能宣称已恢复全部数量或解决旧版 PID rc=2。

兼容校验保留缺字、变体、排版与连续变化轴约束，不静态化可变字体。缺少可信原厂资料时保留当前字体。新增获取路径使用独立只读 EROFS 视图，受本机权限与文件系统支持限制；可复用的原厂快照仍核对版本、路径、大小与 SHA-256。
